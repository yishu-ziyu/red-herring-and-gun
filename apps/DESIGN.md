# 红鲱鱼与枪 · 设计约定

给改界面的人和 AI 看：怎么用已有的视觉规则。产品该显示什么，以 `docs/PRODUCT.md` 为准；版式为什么这样定，见 `docs/DECISIONS.md` 2026-10-10 那条。所有数值以 CSS 为准，从 `src/goldenPath/golden-path.css` 开头的变量块读起，本文件不抄数值。

## 气质

像一份认真排过版的核查报告，不像软件后台。纸色底、深色字、淡线分隔。主次靠字号、粗细和留白分出来，不靠框和色块。

## 结果页的版式（头版式）

- **最先看到判断。** 整句标签用很大的衬线字单独占一行，下面紧跟一句理由。
- **不套卡片。** 原句、结论、每一截、接着问，块与块之间只有留白和一条淡线。不要给任何一块加边框、阴影或底色。
- **标签写在内容上方。** 「结论」「接着问」这类小字标签放在那一块的上面，不放在左边另起一栏：左栏会在长内容旁边留下一大片空白。每一截只在标题前放一个小号圆形数字。
- **证据像脚注。** 一条证据两行：上面是原文那句话（衬线），下面是「方向 · 来源 · 发布日期」（小字）。不要排成表格，不要给证据加彩色底。
- **行距等距。** 同一类块用同一套上下间距；这是用户点名说好的地方，改版时保留。

## 用法

- **新页面不自己定颜色、字号、圆角、动效时长。** 只用 `--gp-*` 变量。成对的同义变量（例如 `--gp-ink` 和 `--gp-ink-primary`）用短的那个。
- **判断的颜色只有四种：绿、黄、红、灰。** 九个标签怎么分到这四种，规则在 `docs/PRODUCT.md`。颜色只做辅助：标签一定写出文字，后面一定跟一句理由。
- **衬线字体只给原句、判断、理由和原文摘录。** 按钮、小字标签、日期、导航用无衬线。
- **焦点要看得见。** 所有可点的东西用统一的焦点环，不要去掉。
- **390px 宽也要能读。** 不出现横向滚动；长原句、长网址要能折行。

## 动效

- 只用来交代变化：内容出现、展开收起、按下按钮。
- 界面动效每段不超过 300 毫秒；出现用先快后慢的曲线，不用先慢后快；不回弹。
- 出现时从略低的位置、带一点模糊浮起，不从很小放大。
- 系统设置了「减少动态效果」时一律不动。

## 不要这样做

- 只显示标签或只显示颜色，不写理由。
- 把搜索引擎名、模型名、「正在调用……」这类执行过程放到界面上。
- 做成数据面板：统计数字卡片、进度环、渐变色块。
- 显示来源总数或证据构成条：同一篇文章被转载会重复计算，要等同文转载合并（#149）以后再加。

## 已知问题，待用户决定

- 品牌酒红和「反驳／不属实」的红是同一个颜色。焦点环、选中状态、强调边框都用品牌红，出现在结果页旁边时，可能被读成「不属实」。
- 判断的四种颜色在 `src/goldenPath/result.css` 里又写了一遍数值，和 `golden-path.css` 的证据颜色重复。改颜色时两处都要改，直到合并。
