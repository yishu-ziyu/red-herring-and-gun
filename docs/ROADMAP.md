# 路线图：用户按顺序看见什么

2026-09-06 用户确定：产品只用五个词对外讲：说法、出处、判断、追问、历史。内部词不许出现在用户面前。
本轮会话定的事优先于历史文档；冲突时改历史文档，不改本轮决定。

顺序按新用户带着疑问进来的眼睛走。一次只定一个，定一个填一个。

## 一、说法（已定）

用户给什么，我们接什么，不改写，不扩写，不前置判断。能收三种：

- 文字：直接收，重复一遍原句请用户确认没理解错。
- 网页链接：把那页正文抓下来当材料，同时留原链，结论里能点回去。抓不到就明说抓不到，不拿搜索摘要冒充原文。
- 图片：读出图里的字，留着原图。现在还找不到这张图更早的出处，没有以图搜图，查到这一步写原图没查到，不把配了同样图的二手帖当成图源。

视频现在收不了，传了也查不了。缺口先记着，不装作能查。

用户给的东西分六种情况（2026-09-06 用户定的处理方式）：

1. 话说不清，一大段混在一起。先查一轮，查完发现搜回来的东西质量很低，再请用户补材料。补什么要说具体，缺时间就问时间，缺地点就问地点。
2. 同一句话反复进来。搬历史，不重新查。历史就是谣言知识库，认出是以前查过的，直接给旧结论。
3. 分几次说完。后补的材料进同一条接着查。用提问的方式弄清楚用户还想补什么，该做的不漏，不该做的不做。
4. 口语和书面语对不上，比如用户说电瓶车，官方写电动自行车。靠模型智能去连，不写死名单。
5. 链接和图坏了。链接打不开、图片没传上来，直接告诉用户这个打不开、那个没收到。不装作查过，这是诚实线。
6. 根本不该查的，比如广告、打招呼、没头没尾一句话。不专门做一套拦截。先认出它不是谣言，直接说我们是查说法的平台，帮不上这个，或者问一句用户希望对这句话做什么。打招呼就好好回一句你好。
