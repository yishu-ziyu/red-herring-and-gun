# 验收矩阵

本文件是要实施的检查清单，不表示仓库现已通过。真实模型/搜索必须与 fixture 测试分开报。

| ID | 场景 | 通过标准 |
| --- | --- | --- |
| A01 | 1440×1000 首页 | 标题、输入、提交与人物组清楚，首屏不被说明和登录挤占 |
| A02 | 1024/390/320px | 无正文横向滚动，无固定栏压住按钮，正文≥16px |
| A03 | 历史 API 延迟 10s | 可提交新材料，非空提交不静默返回 |
| A04 | 双击/回车+点击 | 一个 clientRequestId 仅创建一次 run、登记一次额度 |
| A05 | 输入+链接+图片 | 原文不被抓取正文替换；图片可看、可移除 |
| A06 | 立即进入调查 | 零快照时原材料仍可见，可返回并保留 |
| A07 | 真实搜索启动但无结果 | 仅显示动作，不显示“已找到原文” |
| A08 | 活动重复/乱序 | 同 ID 去重、按 seq 合理重放，终态不倒退 |
| A09 | 活动引用缺对象 | 等快照或显示不可用，不开错来源 |
| A10 | 有限旧事件/no activity | 仍可读快照与最终结果，不要求 fabricated activity |
| A11 | 用户查看较早发现 | 新发现不抢滚动，显示跳转提示 |
| A12 | reduced-motion | 无强制闪烁/移动，可完整操作 |
| A13 | 查找决定性依据 | 从结果出发两次点击内看到片段和来源 |
| A14 | 来源摘要 | 不使用“原文摘录”标签；模型整理另行标注 |
| A15 | 证据冲突 | 两侧分别点击分别打开正确来源；同源转载不冒充独立 |
| A16 | 结论改变 | 保留先前记录与修订信息，不复用陈旧状态 |
| A17 | 网络断开再接 | 不重发创建请求；序号去重；连接状态不同于任务状态 |
| A18 | 刷新 | GET 已有 run/快照，原结果不消失、不重新扣额 |
| A19 | 停止 | 后端确认后显示已停止；不启动下一轮；说明在途调用边界 |
| A20 | 服务端重启 | 已完成报告仍在；未完成标中断，可明确重试 |
| A21 | 保存失败 | 保留结果；可见本地/远端保存状态和重试 |
| A22 | 重查 | 新 run 保留旧 case 版本和原调查时间，不覆盖旧记录 |
| A23 | 旧报告无活动 | 静态展示，说明过程未保存，零模型重建 |
| A24 | 账号 A/B 切换 | 历史与本地镜像按身份隔离，无跨账号上传 |
| A25 | 分享权限 | 未分享的 case 在 /r 与新分享路径均无公开正文 |
| A26 | 显式分享+撤销 | 随机 token、只读字段白名单；撤销后不可再读取 |
| A27 | 私密字段 | 事件/分享/日志无 key、邮箱、system prompt、原始 thought |
| A28 | 登录失败/过期/退出失败 | 状态真实、保留材料、焦点可用 |
| A29 | 案例回放 | 持续显示回放与原时间，零模型/零搜索/零扣额 |
| A30 | 示例来源 | 虚构数据明确标注，禁止发布成真实调查 |
| A31 | HTML / Markdown 注入 | 用户输入、来源文本与分享 JSON 安全转义，不执行脚本 |
| A32 | URL fetch 安全 | 回环/内网/危险重定向不可抓取；BYOK base URL 也受保护 |
| A33 | 200% 缩放+键盘 | 内容可读，弹窗焦点进入/约束/返回，Escape 可关 |
| A34 | SQLite 迁移 | 原 ID/owner/时间/报告保留，重复运行不增行，备份可恢复 |
| A35 | 生产入口 | 真正渲染新组件；不能只在新 demo 路由漂亮 |
| A36 | 服务不可用 / 额度不足 | 不丢用户材料，不擅自新收费；回放仍可用 |
| A37 | 取消时晚到请求 | 旧 run 不污染新 run，终态不会变回处理中 |
| A38 | 幂等请求 payload 不同 | 明确 409 或等价冲突，不能复用错误输入的任务 |
| A39 | 系统失败 vs 证据不足 | interrupted 与 completed+unresolved 区分 |
| A40 | 回放/历史/探针请求 | 不进入核查计费和搜索执行路径 |

## 命令与证据

先核查当前 package.json / 锁文件，按锁文件安装，不盲升版本。基线已知命令：

```bash
# 在仓库根目录，先确认路径和已有脚本
npm --prefix mvp test
npm --prefix mvp run build
# server 单独检查：以其 package.json 的实际 test/build 脚本为准
# 根 workspaces 受改动影响时，再运行根 npm test / npm run build
```

浏览器优先用环境自带工具；没有时用 Playwright。每条核心路径保留截图与相关断言，不只报告 build 成功。真实上游测试需要现成且获授权的测试额度，否则明确不做付费调用。

截图最少：首页；研究中含新发现；结果；来源打开；争议双方；中断；历史；登录/设置；390px 手机首页与结果。每张记录 commit、viewport、fixture 或 real、日期。不要只保存一张所有页面被压小的拼图。
