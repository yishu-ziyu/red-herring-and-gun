# 主任务与子任务草案

以下 ID 只是本包内的任务编号，不是 GitHub Issue 编号。当前未创建任何远程任务。

## RHG-00 / 主任务：恢复调查体验，重构全产品展示
完成条件：RHG-01～08 全部有证据，生产入口使用新体验，用户完成视觉确认；没有假进度、假来源、隐式分享或后台重复扣额。

## RHG-01 / 基线与权限修复（PR-A）
范围：记录工作树和入口；`/r/:id` 与 JSON API 统一私有访问；历史加载不静默阻断新提交。
验收：权限测试先失败后通过；未登录访问他人 case 的 HTML/JSON 无正文；慢历史下提交仅发起一次；保存结果与旧 ID 未丢。

## RHG-02 / 视觉系统与首页（PR-B）
范围：tokens、Shell、输入、附件预览、角色组、教学案例入口、登录/额度空态。
验收：1440/1024/390/320px 无横溢；44px 触控；输入被保留；首页主动作唯一；案例不扣额；截图能看到人物和真实操作，而非截图背景。

## RHG-03 / 调查工作区（PR-B、C）
范围：原材料、问题列表、角色活动、发现流、停止/无进展/断开状态。
验收：零快照时材料仍在；事件重复不增项；过期 run 不污染；每条证据发现可定位；不展示内部思考/供应商日志；reduced-motion 可用。

## RHG-04 / 结果、来源与分歧（PR-B、C）
范围：回答层级、原句关联、证据排序、来源详情、冲突双方。
验收：两次点击内找到决定性材料；原文/摘要/模型整理可辨；左右来源独立；来源失败不是“事实为假”；缺材料不强判；分享摘要不剥掉边界。

## RHG-05 / 活动投影与传输（PR-C）
范围：PublicActivity 判别联合与校验、pipeline hooks、模板文案、稳定 ID、revision、序号与重放。
验收：没有引用对象不产生事实发现；秘密/原始 thought 不进入事件；乱序/重复/丢帧/未知版本均有测试；活动层降级不阻塞结果。

## RHG-06 / RunService 与持久化（PR-D）
范围：任务身份、SQLite repository、迁移、幂等创建、所有权、SSE、取消、deadline、保存。
验收：双击一次执行一次扣额；刷新不新跑；断网回连不重复事件；重启保留记录且未完成标中断；取消不启动下一轮；迁移可复跑、可回滚；密钥不落库。

## RHG-07 / 历史、分享、设置（PR-E）
范围：匿名/账户隔离、查历史、重查新 run、显式分享/撤销、账号设置。
验收：账户 A 不看到 B；历史不耗额度；无分享许可的 case 无公开页；撤销后链接不可继续读取；登录不清空材料；退出失败不假装退出。

## RHG-08 / 清理与发布证据（PR-F）
范围：生产只剩一个视觉入口；旧报告兼容；测试、截图、文案、无障碍、发布回滚说明。
验收：没有无引用的新 demo；无假指标与不可靠宣传；桌面/手机完整交互路径通过；用户批准后才合并/部署。删除旧代码逐项证明没有消费者。
