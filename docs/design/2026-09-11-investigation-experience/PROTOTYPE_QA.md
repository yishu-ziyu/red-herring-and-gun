# 原型检查记录

范围：本包 prototype.html，非仓库修改验收。所有材料与进展均为明示的虚构教学 fixture。

## 运行环境与限制
Browser 插件未提供。使用 Playwright + 已安装的系统 Chromium。默认 Playwright 浏览器二进制不存在，未安装新依赖。当前容器的 file:// 与 localhost 页面导航被管理策略阻止，使用 `page.set_content` 在浏览器内存中渲染本地 HTML，运行同一份 JS/CSS。没有访问远程网页或调用模型。

因此，已验证的是离线 DOM 渲染与交互，不是外部 URL 可达性或部署。原型仍为可自行打开的单 HTML；本次不声称测试了用户设备上的 file:// 行为。

## 通过项
- 1440×1000：10 个页面/状态都有标题与有效主内容，未发现横溢。
- 390×844、320×844：分别检查 6 个核心页面，无文档级横溢。
- 首页填入案例 → 提交说明 → 明确回放 → 1/2/3 条发现 → 结果。
- 争议两侧来源分别打开正确的材料，Escape 关闭。
- 历史关键词无匹配时出现正确空态。
- 分享披露 → 分享预览，明确未创建真实链接。
- 任意用户输入不会被直接变成虚构公园结论；关闭说明后草稿保留。
- JS pageerror 与 console warning/error：详见 prototype-qa.json，最新运行未记录错误。

## 视觉检查与有意调整
已查看原概念与实际截图。对比项：
1. 文字：删掉虚构指标、真实感新闻和医疗结论；所有示例标明虚构。
2. 结构：首页一个主操作，过程有原材料与发现流，结果有明确回答和证据。
3. 人物：从四个大半身立绘缩为独立头像，减少抢占正文。
4. 配色：浅暖灰底与暗红品牌；不以绿色成功框呈现反驳结论。
5. 排版：结果使用阅读型文稿，界面正文与元信息有层级，不套多层卡片。
6. 响应式：手机单列、证据侧栏改底部面板。
7. 控件：原型页面选择器已移到正常文档流，避免覆盖主要按钮。

这些是未批准概念的明确修正，不是宣称“像素级忠实于已批准设计”。实际审美由用户确认。

## 尚未验证/实现
真实模型搜索、后端鉴权和取消、恢复与迁移、真实分享与撤销、实际账号与密钥、输入图像识别、收费、生产性能、生产的完整无障碍审计。

原型的原句下划线为视觉示例，生产需要实现到命题的悬停/键盘/点击关联。原型角色只是教学阶段，生产必须接真实事件。登录、设置、导出等按钮提供原型说明，不执行真实账户操作。
