# 红鲱鱼与枪 · Codex 交接包

先看 `prototype.html`：一个不依赖安装、不连接网络的单文件页面原型。浏览器打开后，页面底部菜单可切换 10 种页面/状态。首页选择教学案例可以逐步回放，证据按钮能打开来源，两侧材料分别可点；历史支持搜索。

再把 `START_HERE.md` 发给 Codex，并让它读取本包文件。`IMPLEMENTATION_PLAN.md` 是完整实施方案，`ISSUES.md` 是主/子任务草案，`ACCEPTANCE.md` 是 40 项产品验收清单，`REFERENCES.md` 说明各页面借鉴什么。

`concept-original.png` 是上一条消息生成的概念拼图，有虚构来源、阅读数和错误语义色，不能直接作为成品。以 prototype.html 作为修正后的视觉提议，等待用户审美确认。

`screens/` 包含 10 张桌面和 6 张手机完整页面截图。`prototype-qa.json` / `PROTOTYPE_QA.md` 是本包原型的实际检查结果；不代表真实仓库通过测试。

角色头像裁自已有生成概念，仅是提议素材；品牌小图形也是原型符号。生产优先复用并核实仓库旧 logo 和头像，不把它们误认为已批准的新品牌。没有包含字体文件。

本包不包含生产代码改动、真实调查结果、用户账户内容、可用 API Key 或已发布网站。未向 GitHub 创建 Issue、提交、合并或部署。
