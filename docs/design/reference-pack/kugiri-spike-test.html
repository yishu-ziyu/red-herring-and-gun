测试维度 kugiri (0.4.0) 表现 现代 CSS / 原生 DOM 表现 评估裁决
中文长句分词准确率 基于 Intl.Segmenter，词形偶有错切（如“都应该”切为“都”+“应该”） 依赖浏览器完整文本渲染，保持字距原生渲染 平手偏原生
中文标点与换行禁则 拆入 span 后，若跨行，部分标点挤压规则失效 浏览器原生遵循 line-break: strict 原生胜出
inline a / strong 标签 跨行切分会克隆标签，增加 DOM 节点数与事件丢失风险 DOM 节点保持单一身份，链接与事件天然完好 原生胜出
text-wrap: balance 拆分时计算的行位置会因 balance 再次变动产生冲突 浏览器内部 GPU / 排版引擎一次性计算 原生胜出
视口动态 Resize 必须挂载 ResizeObserver，频繁 revert() + split()，引发重排抖动 零 JS，纯浏览器流式重排，性能消耗近乎为 0 kugiri 劣势
Screen Reader 朗读 若未显式加 aria-hidden 与 aria-label，会拆成单字顿挫拼读 整句完整呈现于 Accessibility Tree，语调自然连贯 需额外防护
Claim Trace 交互 过于笨重；需要针对字词注入 mask，无法精准响应语义 span 通过 <mark data-span-id> 语义驱动，简单优雅 原生极优
Conclusion Emergence 可提供整行向上推的 mask reveal 动效（视觉精致） CSS 配合 clip-path 或 Framer Motion 亦可完全实现 均可实现
