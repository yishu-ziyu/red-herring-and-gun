# 2026-09-04 · 免费源预置，收费源用户自己填

## 改了什么

检索拆成两类：AnySearch（及配了地址的 SearXNG）预置；360 / 秘塔 / Tavily / Exa / 博查 / Brave / Jina 要用户自己的密钥。产品里加了 `/settings`：开通、充值、贴密钥、保存。

## 为什么

四家收费源额度死了，但 AnySearch 匿名仍能搜。再让运维去充值解决不了「别人怎么用」。开源侧能当真免费、零密钥、国内可用的聚合 API 几乎没有：DuckDuckGo HTML 被拦，Jina 搜索要密钥，SearXNG 要自建。能做的是预置还能用的源，并把收费源的开通/充值放进产品。

## 结果

空密钥矩阵只打 AnySearch，仍 6 条命中。设置页分组清楚。用户密钥只接受目录里的收费源字段，不能塞任意 URL。
