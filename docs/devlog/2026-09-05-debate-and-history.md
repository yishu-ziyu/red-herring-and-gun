# 回到质询与调查积累

用户批准的方向：这是 side project，不以战胜 Google 或 Perplexity 为目标。让用户看见一条说法如何经受有证据的质询，并使每次调查成为下一次的起点。

本轮交付：生产 mvp 上的有界质询、结果页的关键交锋与出处、自动留存和显式历史复用。沿用现有页面、存储及套餐适配器，不另建运行时，不执行 T20。完整自动语义复用、全库导入、跨用户知识学习暂不加入；同句找回和显式打开旧报告先闭环。

研究仅支撑机制假设：MADR (https://arxiv.org/abs/2402.07401) 研究给定证据下解释忠实度；Debate or Vote (https://arxiv.org/abs/2508.17536) 提醒区分独立采样收益与辩论收益；Full Fact (https://fullfact.org/ai/) 的重复说法匹配说明历史调查复用的实际用途。论文不验证本仓库的手工分数或产品准确率。

旧 PRODUCT_SPEC 中“无人做到”“其他产品永远有答案”及定位图中的高低排序不再作为产品事实或实施依据。旧文的“多 Agent 只是流水线”“不做自治”也不限制这次已批准的有界行动循环。引用、原句范围、错误透明等底线继续保留。

执行由本会话协调者与原生子 Agent 完成。GPT-6 Astra medium 用于有判断要求的任务。原生工具展示的模型列表没有 Spark，但用户要求实际尝试后，`gpt-5.3-codex-spark` + `xhigh` 的子 Agent 创建成功并完成只读任务；没有额外 served-model 回执。后续极小任务可按此参数委派，不再依据展示列表断言不可用。CMUX Grok 已由用户取消，不再操作。共享工作区已有未提交改动，写入单元串行，协调者保留独立验收用例并负责真实用户路径。
