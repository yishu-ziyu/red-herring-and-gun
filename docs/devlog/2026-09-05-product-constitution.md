# Product Reset：产品宪法与 Golden Path 契约落盘

2026-09-05。Issue #49 定方向，#50 落契约，本篇记录方向变更本身；现行规则以 `docs/PRODUCT_SPEC.md` 为准。

## 变了什么

产品主叙事从「追出处、告诉你能信不能信」改为「可检查的信息调查工具」：把说法拆成可核查命题，追查公开证据，展示每个判断如何从证据与证据缺口中形成。PRODUCT_SPEC 第一、二节重写为宪法：Evidence Auditability > Agent Observability、复杂调查简单理解、白盒三层（命题 / 证据 / 判断透明）、唯一 Golden Path（输入 → 命题拆解 → 证据汇入 → 冲突/缺口 → 判断 → 来源下钻）、实现层默认隐藏、视觉体验属产品门禁。

## 废止的旧假设

- Mission Control（指挥台）是产品脸 —— 废止。执行过程（Agent、tool call、provider、token、模型推理、内部日志）默认隐藏；调查逻辑（原句 → 命题 → 证据关系 → 缺口/冲突 → 判断）默认可见并渐进呈现。两个对象分开，不再用「过程默认收着」这种会误伤调查逻辑的说法。
- 多 Agent 角色必须前台展示 —— 废止，多 Agent 是实现层编排，默认不以 Agent 术语出现在前台。
- 可信度数字代表白盒 —— 废止，数字是实现层辅助信号，白盒是三层透明，数字不替代证据解释。
- README 承诺「告诉你能信还是不能信」—— 废止，那四个词是内部 verdict enum；用户得到的是对原句的直接回答与证据解释。
- 「类型闸在产品里不可见是产品缺陷」（2026-08-19 记录）—— 废止，模型 / provider 归属默认隐藏；产品层对应命题透明。
- 旧主路径图「材料进来 → 追出处 → 直接回答原句 → 问题在哪 → 来源」—— 由唯一 Golden Path 取代，追出处收进证据工作。

## 与既有决定的衔接（不是推翻）

- 五词规则（`docs/ROADMAP.md`：说法、出处、判断、追问、历史）保留，但按 PR #55 人工验收降级为顶层产品语言与导航骨架，**不是封闭词表**：证据语义（支持、反驳、仅相关、尚缺、争议）必须能直接出现在用户面前。ROADMAP 现行规则已同步修订服从宪法，PRODUCT_SPEC / ROADMAP / devlog 之间只有一套现行规则。
- ROADMAP「拆分过程不呈现，只呈现分段结论和出处」原句已按人工验收修订为精确定义：不展示模型推理、中间尝试和内部拆题日志，但必须展示最终拆分结果，并让用户能对照原句检查是否改题。
- 证据语义按人工验收定死：支持 / 反驳 / 仅相关必须绑定可点开出处；尚缺是一等 Evidence Gap，写明缺什么、为什么阻止更强判断，无来源就明确无来源，不许为凑链接把 related-only 当支撑。
- 章节号未动：`docs/reviews/` 大量按第四节 / 第六节 / 第七节 / 第八节引用 PRODUCT_SPEC，宪法内容折进原有第一、二节，CONTEXT 的「§四 类型谁标」引用仍有效。
- 后端能力一个不删：质询、留存、证据追索保留为现行规则；五词规则经 PR #55 人工验收修订后保留（降为顶层产品语言与导航骨架）。

## 边界

本轮只改契约文档（PRODUCT_SPEC / README / CONTEXT / eval / devlog / NOTES），未动任何代码。#51（白盒数据契约）起才涉及实现；#50 关闭需人工验收，验收尺度见 `docs/evals/2026-09-05-product-constitution.md`。

## 未裁决的歧义

PR #55 人工验收裁决了两条，已了结并写进现行规则，不再是歧义：五词与宪法词汇的关系（定为「顶层骨架 + 证据语义支持/反驳/仅相关/尚缺/争议直出」，ROADMAP 已同步修订）；「拆分过程不呈现」与命题透明的边界（定为「不展示模型推理、中间尝试和内部拆题日志，必须展示最终拆分结果并可对照原句查改题」）。剩余：

- `credibilityScore` 是否继续在结果页展示、以什么形式展示，#50 没裁；本契约只定了「数字不替代证据解释、不属于白盒三层」。
- 「仅相关」证据类别：现有管线证据分类没有明确的仅相关用户文案，契约先行，数据契约留给 #51。
- Golden Path 的「冲突/缺口」步骤与现有 evidenceLoop / crossExam 的映射粒度未定，留给 #51/#52。
- 赛题 10% 多 Agent 权重与「Agent 是实现层」并存：赛题权重已标不作为本轮价值函数，黑客松评审要看多 Agent 时展示什么，留给 #52。
