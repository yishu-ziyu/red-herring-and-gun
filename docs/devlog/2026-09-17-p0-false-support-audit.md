# 2026-09-17 P0 级重大事实判定事故：辟谣反驳被误判为「支持」与合集标题串号

## 事故背景与用户真机测试发现

在用户针对真实中文流传说法进行真机测试时，发现并捕获了一起违背产品立足之本的致命事实颠倒事故：

- **测试输入**：“气泡水是碱性的，所以可以中和酸。因此，当胃有些不舒服的时候，喝苏打水就够了。”
- **引用来源**：央广网《喝气泡水可以降尿酸？真相来了》（`news.cnr.cn`，发表于 2023-05-02）
- **央广网原文实录**：
  > “流言：喝气泡水可以降尿酸”
  > “真相：气泡水经饮用后，所含的二氧化碳进入人体会产生碳酸氢根离子——碳酸氢根属于弱碱性离子，具有一定的中和尿酸的作用，**这也是流传说法中‘气泡水降尿酸’的主要‘依据’**。”
  > “**但是面对强大的人体系统，气泡水的酸碱中和能力实在是‘杯水车薪’，根本无法引起人体的酸碱变化，更实现不了降尿酸的治疗作用**。其实，气泡水具有更清新的口感...纯粹以快乐为目的去喝就可以了。”

## 系统表现与致命错误

1. **事实颠倒与断章取义（Fatal Contradiction）**：
   - 抽屉顶部赫然打着绿色的 **`● 对这条命题：支持`**；
   - 摘录只截取了流言借用的化学原理解释：“*气泡水产生的碳酸氢根属于弱碱性离子，具有一定的中和尿酸的作用*”；
   - 系统的核验洞察正文写道：“*央广网科普指出，气泡水产生的碳酸氢根属于弱碱性离子，理论上具有一定中和尿酸的作用[2]。但同时强调，面对人体系统，这一酸碱中和能力‘杯水车薪’，无法引起人体的酸碱变化[2]。*”
   - **正文明明在写不可行、无法引起变化，顶部的徽章却宣布「支持」！系统直接推翻了自己的论据，成为造谣者的传声筒。**

2. **合集网页标题张冠李戴（Crawler Title Pollution）**：
   - 抽屉显示的文章大标题为：**《长期戴眼镜会变金鱼眼?未见得》**，正文内容却在讲喝气泡水。
   - 根因：央广网发布的是一篇多合一「假期辟谣合集」，爬虫机械抓取了页面的全局 `<title>`，完全没有根据命中文段就近锚定所在的小节标题。

## 根因分析（Root Cause）

1. **机械拆题引发语境剥离**：
   - 系统将“胃有些不舒服喝苏打水就够了”拆解为孤立命题“气泡水可以中和酸”；
   - 模型脱离了人体医学语境，落入了纯化学理论匹配，给出了弱智的“支持”判断。
2. **缺乏对抗「先扬后抑」辟谣文体的判别逻辑**：
   - 权威科普普遍采用“虽然原理上有微量成分（扬），但在人体中杯水车薪根本不成立（抑）”的文体；
   - 模型被前半句抓取，未建立强制否定门禁。
3. **爬虫抓取层缺乏 Subheading Anchor**：
   - HTML 页面抓取只认 `<title>` 或 `og:title`，缺少段落最近的 `h2 / h3` 祖先/前置锚点识别。

## 修复验收契约

- **Change**：
  1. `fact_checker` 与 `conclusionGate` 中增加反转对抗规则：当来源正文明确为“辟谣/流言”，或明确指出实际效果“杯水车薪/无法引起变化/不能代替治疗”时，该命题严禁归入 `supportingSources`，必须强制归入 `contradictingSources`（反驳），并展示反驳标签。
  2. 爬虫提取网页标题时，增加就近小标题匹配逻辑（段落往前查找最近的 `h2 / h3 / b / strong` 标题），消灭合集页面标题串号。
  3. 系统正文分析与标签状态强一致性检查：若解释中包含否定性转折，标签不得为绿色支持。
- **Not this**：
  - 不得以“微观化学角度确实有中和反应”为由辩解；
  - 不得以“模型输出不可控”为由放弃防御，必须有规则门禁兜底。
- **Evaluator**：
  - 编写专门的单元测试用例，重放该真实 CNR 文章快照，断言其关系判定必为 `contradict`，且标题不得为《长期戴眼镜会变金鱼眼?未见得》。
