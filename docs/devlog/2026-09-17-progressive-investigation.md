# 默认产品逻辑采用方案二

用户选择：普通人为优先服务对象，自动识别材料并开始调查；同一份调查先解决主要问题，再让有需要的人深入核对。三种候选方案中，方案二成为默认，不再等待转交任何协作者。

重要区别：查看已有依据不等于重新查证；补查是用户明确发起的新工作，须保留前轮结果和日期。调查范围由真实命题/计划决定，不用词面残句替代，也不对整篇材料盖章。

本次不加思考强度滑条。方案一到三并非同一维度：既改变覆盖范围，也改变交付形式。未经验证的时限档位不能冒充调查深度。暂按用户允许的备选，固定方案二。
