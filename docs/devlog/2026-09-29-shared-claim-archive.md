# 2026-09-29 说法档案：预收集 + 自更新 + 公共说法共享

用户裁决：说法档案既预先收集已有辟谣，也把用户查过的说法逐步加进去（自更新）；公共说法去掉提问人信息后所有人共享，涉及普通个人或私人群聊的不进共享档案。取代「不跨用户汇总」在公共说法上的适用。

## 为什么

- 同一件事被第二个人问到时，档案能直接给出带日期的结论，速度和一致性都来自这里。
- 只靠预收集不够：辟谣平台 2422 篇（2025-06 至今）对 40 条回答基准命中约 0–3%。自更新的价值要用「问第二遍」检验（换说法应命中；换时间地点数字应识别为变体、不继承结论）。

## 顺序与约束

- 先把「挑出关键出处」和关系判断做准，再打开自动写入：写入会放大当时的准确率，判错的结论会被更快、更可信地复制。
- 写入门槛：判断所用原文经代码回查；标明来源类型（权威辟谣 / 本系统核查）；结论按版本追加、带日期。
- 同一说法以真值条件相同为准（Full Fact 定义）；变体归入同一家族，只提示、不继承。
