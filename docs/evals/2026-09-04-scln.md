# 2026-09-04 · 本仓库落地 SCLN 协作层

一句话：新会话按短协议做事；压缩后能从 NOTES 恢复；这一次什么叫好写在 evals 里。

## Change

打开仓库，Agent 默认读短的 `AGENTS.md`；当前状态在 `docs/NOTES.md` 头部；本任务的成功标准在 `docs/evals/`；方向改变进 `docs/devlog/`；可迁走的完整包在 `docs/METHODOLOGY.md`。

## Not this

- 在 `runtime/STATE.md` 旁边再加一层，两套一起用
- 把产品品味、某次踩坑写进 `AGENTS.md`
- 本轮建 wiki 或改 skill
- hook 继续自动覆盖工作记忆

## Evaluator

- `wc -l AGENTS.md` 小于 80；文中有：验收标准、现象即信号、压缩后读 NOTES、能合并的真实命令
- `AGENTS.md` 不含排版/配色/技术选型段落
- 存在 `docs/METHODOLOGY.md`、`docs/NOTES.md`（开头是「当前状态」）、`docs/devlog/` 至少一篇、本文件
- `runtime/STATE.md` 只指向 NOTES，不再由 `session_start` 生成任务表
- `runtime/bin/stop_gate.py` / `precompact_remind.py` 检查的是 `docs/NOTES.md`，不是 `runtime/tasks/`
- `python3 -c "import ast; ast.parse(open('runtime/bin/lib.py').read())"` 退出码 0
