# 清理被取代的界面材料

## Change

用户认可两份设计后明确要求删除其他旧稿。删除旧界面 HTML、未选用截图、Apodex 外观复刻、参考视频及逐帧图片、已否定的首版结果原型；不另建备份目录。保留认可的两个展示目录及跨目录依赖，以及当前结果页修正版。

## Not this

此次不删除生产组件、业务代码、新版开发代码、运行数据或密钥；也不把路演材料、技术决策记录和第三方研究代码混作旧界面删除。

## Evaluator

- 删除清单逐项不存在；认可稿及其材料逐项校验 SHA-256 不变；运行代码和非旧稿公共资源校验不变。
- 重建总览，移除被删稿件及缩略图入口；浏览器打开两份认可稿，配图完整，零件选择仍可操作。
- 续做文档、设计索引与运行地图不再把删除材料当作可用入口；历史验收记录标明其附件已清理。
- 本次无产品行为变化，不运行真实模型或搜索，不以构建/旧门禁替代文件与浏览器检查。

## 结果

- 已删除 551 个文件，约 69.4 MiB；删除清单逐项确认不存在。
- 两份认可稿的 57 个文件 SHA-256 不变；836 个运行代码、配置及非旧稿资源的 SHA-256 不变。
- 精简后的总览 142 项，133 个允许读取的本地资源 HTTP 全部成功。路演和技术记录保留，但已移出界面目录。
- ChromeMain 从新总览实际打开两份认可稿：零件页 11 张图片、路径页 18 张图片全部加载；“不要”选择更新了汇总，随后恢复默认。没有改变用户的文件或持久化选择。
- 索引、NOTES、续做记录、原型验收和架构地图已同步删除状态；旧盘点数字标明为清理前记录。git diff --check 通过。
- 未运行产品测试、build 或 eval:gate；本次没有运行代码或产品行为变化，没有真模型/搜索调用。
- 精确删除清单与保留文件哈希位于本地 `.context/design-overview/cleanup-plan.json`，仅记录路径和哈希，不保存已删除材料副本。
