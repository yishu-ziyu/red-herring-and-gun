# 现有设计与界面总览

## Change

把项目文件夹中的两套前端、独立 HTML、设计说明、界面截图及视觉素材汇集到可浏览的本地总览，保留原件与路径，注明当前产品、新版开发、待评原型、历史记录和外部参考。

## Not this

不重画产品，不接生产质询，不用历史截图证明当前界面或真实调查已验收。排除依赖、构建重复、第三方克隆仓库内部网页和抓取测试用 HTML；原项目截图、展示稿和设计存档保留。

## Evaluator

- 机器：清单中的本地资源存在，HTTP 返回成功；仅清单内文件可通过总览服务读取。
- 浏览器：从总览打开当前产品、新版本地 fixture、旧 HTML、历史截图和设计说明；验证分类筛选、搜索、关闭预览及 390px 展示宽度。
- 人评：用户能找到自己指的旧版设计，并判断当前原型与它的差异；不预判用户认可。

## 结果

- 已生成本地总览 <http://127.0.0.1:51911/>，清单 718 项，其中 337 项为单独分类的视频帧；15 份独立 HTML、224 张历史界面图、61 个界面源码文件，其他为实时入口、说明和视觉材料。
- 709 个允许读取的本地资源 HTTP 检查全部成功；未列入清单的路径返回 404。
- ChromeMain 实际从总览打开 mvp 首页、新版完成 fixture、既有新旧对照 HTML、设计规范和搜索命中的历史截图；对照页 5 张配图均加载成功。分类与搜索、关闭预览、390px 按钮已操作；新版固定结果页 clientWidth/scrollWidth 均为 390。
- 总览只展示现存文件和开发页面，没有提交新调查、模型/搜索任务，也没有修改产品行为。不运行根测试、build 或 eval:gate；这些不能评价本次只读素材目录。
- 未逐项验收所有历史原稿的内部交互，未把 fixture、历史截图或待评原型作为真实调查完成证据。人评仍由用户判断。
- 可恢复索引与启动命令：`docs/design/2026-09-05-interface-index.md`。

## 用户裁决

2026-09-05 用户看过界面总览后，明确认可 `packages/web/output/show-me-parts/index.html`（既有零件展示：要 / 不要）和 `packages/web/output/show-me-walk/index.html`（既有用户路径走查：桌面与手机）的设计。后续原型以这两份为具体视觉与交互基准：前者参考零件呈现，后者参考整体界面及桌面/手机路径。此次认可不等于逐项选中了零件页的所有候选，也不等于认可本轮新增质询的 A/B 位置；原稿内的旧开发状态不因此恢复为当前事实。 总览将两份原件置顶并标注认可状态，原件内容保持不变。


### 用户要求清理旧稿后的状态

2026-09-05 用户确认设计基准后，进一步要求删除其他旧界面材料。已删除 551 个文件（约 69.4 MiB），包括旧 HTML、截图、参考视频和被否定的首版；两份认可稿及依赖的 57 个文件保持不变。总览已精简为 142 项，当前入口见 `docs/design/2026-09-05-interface-index.md`。前述全量盘点数量属于清理前记录，已删除附件不再作为可打开入口。结果修正版仍待按认可基准对齐并评审，生产接线未推进。
