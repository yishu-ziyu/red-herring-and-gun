# 有效质询、清楚呈现、历史复用

用户于 2026-09-05 批准。协调者独立验收；实现者只接收本单元的功能目标与接口约束，不读取本文件或独立保留用例。保留用例不等于对共享磁盘的安全隔离。

## 价值函数（2026-09-05 再确认）

用户得到一份能理解、能追溯、能继续使用的调查。优先次序是：先守住证据诚实和私人数据边界，再完成整个使用路径，然后改善质询的实际帮助、界面可读性与重复使用成本。不把这些相加成一个人为加权分数；速度和视觉不能抵消编造证据或泄露历史。

| 用户价值 | 可以观察的结果 | 工程判断方式 |
| --- | --- | --- |
| 这次确实帮我查了 | 直接回答原句；有出处的判断与尚未查清的部分分开 | 管线输入/输出与引用校验；真实提交后逐项读原文核对，不把 URL 存在等同语义正确 |
| 我看得懂为什么 | 关键质询有对应回应，能点开改变判断的出处 | 浏览器从结果打开质询和引用；人评回答“争点是什么、证据说明了什么、还有什么未知” |
| 我以前没有白查 | 完成的五次调查刷新后仍在，打开无需再启动调查 | 五次保存→重载→逐条打开；断言新模型/搜索调用为零、报告与时间未被重写 |
| 复用不会骗我 | 明确显示旧调查日期；同句可选择打开或重查，变更人物/日期不继承 | 相同/近似/时间变化用例，登录切换、晚到响应和存储失败回归 |
| 它值得花这些成本 | 质询能指出具体缺口，补查或回应留下可检查的变化；重开避免重复调用 | 记录纠正及引入错误、搜索和模型次数、耗时；不以轮数、共识或分数上涨代替收益 |

### 本轮边界与退出规则

- 第一版同句找回只规范化空白，语义相似只提供搜索线索。自动继承判词不在本轮。
- 本地访客历史属于该浏览器；登录历史按账号分开。未经用户同意不跨用户汇总私人调查。
- 质询最多覆盖两个争点、每个争点一轮有界补查及回应；使用现有总截止时间，不增加无限循环。预算不足保留“未完成质询”，不得补演已完成。
- 质询如果只增加重复文字，或在保留案例上引入新的无据定论，该单元不交付；缩小触发范围或修正实现后重验。不会为了展示多 Agent 强行制造冲突。
- 机器项失败就继续修复或如实报告具体阻塞；用户只裁视觉、易懂程度以及是否值得保留。无需用户代跑命令、整理日志或提醒执行者汇报。

### 工程单元与依赖

1. 历史：保守匹配键（Spark，已完成）→ 账号作用域存储与历史页面接线（GPT-6 medium）→ 协调者浏览器验收。
2. 质询：真实证据绑定、独立意见、具体缺口补查、主调查回应（GPT-6 medium）→ 协调者管线验收。
3. 呈现：消费实际质询记录，默认只显示关键争点及出处，兼容没有记录的旧报告 → 协调者桌面/窄屏验收 → 用户人评。
4. 集成：真实调查→自动保存→刷新→重开→主动重查；运行项目规定检查，记录旧门禁的既有失败。前一单元没完成接线，不把叶子函数当作交付。

只用既有生产 mvp、已有套餐与存储。不升级基础架构，不发布公网。后续部署需要明确授权。

## Change

- 首次核查存在争点时，独立调查意见可以提出具体证据缺口，触发有界补查；主调查能够回应并更新或保留判断。Evaluator：协调者以注入模型与搜索的管线集成测试记录实际调用顺序、传入材料、证据变化及最终报告；再运行一次真实模型/搜索的用户路径。仅有测试不能证明真实质询有效。
- 结果页显示实际发生的关键质询、回应、出处及仍未解决的问题，原句的直接回答仍在第一层。Evaluator：实际浏览器走完提交→结果→展开质询→打开引用；桌面与窄屏无横向溢出。不存在质询时不补造交锋。视觉是否优雅由用户人评。
- 每次完成的调查自动留存，重新打开不调用模型或搜索，显示原调查时间并能主动重新核查。Evaluator：真实页面完成保存、重载、打开旧案，检查网络无 orchestrate 请求；存储失败必须可见，不能声称已保存。账号/本地访客边界明确，不共享私人历史。
- 相同文字可找回历史调查，时间敏感或仅主题相似的输入不能静默继承旧结论。Evaluator：独立测试同句、空白变化、时间变化、人物变化、失败记录；观察明确的打开旧案/重新核查选择及调用计数。

## Not this

- 不声称优于 Google、Perplexity，不以旧可信度区间作为本轮成功目标。
- 不补演 Agent 对话，不用共识或多数票替代证据，不用第一/最后几条检索结果冒充支撑与反证。
- 不重建通用记忆框架、知识图谱、训练系统，不切换生产壳，不改 ops.sh，不删除 mvp。
- 不发布、不覆盖已有未提交工作、不把尚未通过的机器项写成完成。

## Evaluator

- 协调者：审查本轮增量、运行定向测试、根 npm test / npm run build、mvp npm test / npm run build；行为变更运行 npm run eval:gate，旧门禁失败逐项记录，不篡改门禁获取绿灯。
- 质询价值：相近资源下比较单调查、独立意见汇总、加入质询，记录纠正/引入错误与调用量；本轮小样本仅用于决定是否保留实现，不作准确率宣传。
- 记忆成本：报告实际避免的搜索/模型调用，不推测节省金额。
- 人评：关键争点是否易懂、出处是否容易找到、视觉与交互是否接受。

### 已实现并由协调者复核

- 历史：匿名及账号分别自动保存，刷新后读取、打开旧报告不启动调查；同原句显式选择旧调查/重查；新链接或图片不误命中。保存失败、退出失败和晚到响应有防护。
- 评论与追加输入：身份未确认时不加载、不写入；账号和访客分开；旧全局记录保留原样，不自动归属当前用户。存储不可用时提示而非崩溃。
- 质询：实际引用绑定，最多两个争点各一轮独立意见、可选补查、主调查回应，结果保存到 crossExam。生产取消“分歧即扣分”。报告摘要及兜底都读取最新调查。
