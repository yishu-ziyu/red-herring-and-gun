# 2026-09-05 · 提前停止必须经独立复核

一句话：完整事实句不能因单次资格模型误判而被赶回去补一个本来就存在的对象。

## Change

- 首次资格判断认为材料不够核时，用独立工单重新检查材料中是否存在完整判断，并从原文抄出主体与命题。
- 复核只能凭原文连续片段翻转为进入核查；找不到唯一原文锚点时仍停止，不能补写用户没说的对象或事件。
- 两次停止或复核不可用时保留安全停止；一次模型误判不得成为完整事实句的最终结果。

## Not this

- 用某条谣言、关键词或句长白名单强行放行。
- 只改提示词后用一次成功运行宣称稳定。
- 复核输出无法锚定原文也继续检索。
- 为了提高进入率，把纯请求、空指代词或立场句送进事实判断。

## Evaluator

- core 单元测试：首次错误返回 missing_object，独立复核从原文提取合法主体和完整命题时进入；复核虚构片段时仍停止。
- core 单元测试：纯请求、无先行词空指、只有应当/好坏立场在两次判断后仍停止。
- 真实重复回归：同一完整事实句连续运行不再出现一次进入、一次提前停止；每次停止都能在事件中看到复核工单。
- 回归：core 全量、eval 全量、根测试与构建通过。

## Goal / Hard bar / Improve

- Goal：资格闸只挡真正缺材料的输入，不把模型波动伪装成用户输入有问题。
- Hard bar：完整事实句不误停；复核不能越过原文锚定；无事实输入不误入。
- Improve：有人工资格标签后，分别统计 false-stop 与 false-enter，先把 false-stop 稳定性做成重复运行指标。
