# 2026-09-05 · 报告不得扩大证据范围

一句话：报告中的每个事实性解释都必须由对应命题的引用原文支持，不能在写作阶段丢掉主体、平台、条件、时间或限定词。

## Change

- 当前出口不再接受无法确定性验证的自由解释：命题行只由原命题、既有判词和该命题的合法引用组成；引用只反驳具体场景时，报告不得写成对整个类别的普遍断言。
- 原句或证据中的主体、平台、条件、时间、数量和否定限定必须保留；不能把“正常显示的问候图片”扩成“图片本身”，也不能把“目前未发现”扩成“不可能”。
- 判词方向仍由已完成的命题裁决决定；语义审查只约束报告怎么表达依据与边界，不自行改变判词。
- 不能证明安全范围的解释应删除或收窄，保留直接回答和可点击引用。

## Not this

- 只检查引用编号存在，就把报告称为无幻觉。
- 为某一条谣言写关键词特判。
- 把所有报告降级成“证据不足”来避免犯错。
- 只改 UI 标签或把过度断言藏到折叠区。

## Evaluator

- 单元测试：引用只支持带平台和“正常显示”条件的结论时，组合结果不得删除这些限定词或改成类别普遍断言。
- 单元测试：引用只说“未发现通报”时，不得输出“不可能发生”；引用只覆盖某时间/地区/主体时，不得扩到全部时间/地区/主体。
- 单元测试：审查失败后的修复仍保留第一句直接回答、原判词方向和合法引用，不得统一降级。
- 结构检查：报告中的引用编号都绑定该命题的 basis；事实性句子不能只靠模型常识补充。
- 真实回归：由盲评者对原句、引用原文和报告逐句比对，范围扩大计失败；旧的结构型引用完整率单列，不再冒充语义幻觉率。

## 未解决边界

- 出口收紧只能阻止写作阶段新增事实，不能证明上游 `stance` 与命题是同一事实，也不能把错绑的 evidence 从 basis 中删除。
- RUMOR-005 已实测出现“中毒 + 信息被盗”合成一条命题、basis 主要覆盖中毒的情况；这需要命题拆分与同事实证据契约，不能用字符重叠冒充语义蕴含。

## Goal / Hard bar / Improve

- Goal：用户看到的不只是“带引用的答案”，而是没有越过引用边界的答案。
- Hard bar：判词方向不变、限定不丢、无证据支撑的机制解释不进入报告。
- Improve：积累范围扩张失败后，按主体、时间、数量、条件、模态五类统计，优先修复最高频类别。
