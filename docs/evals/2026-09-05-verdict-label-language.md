# 结果判词不用命令用户“信多少”

## Change

- 结果标签描述核查状态，不替用户决定应该相信多少。
- 多个命题有真有假时写“有真有假”；单个命题只成立一部分时写“部分成立”；证据不足仍写“还查不清”。
- 标签、分享文案、逐项判词和无障碍文本使用同一套语义，不能把不同状态重新合并成一个口号。

## Not this

- 只改截图中的一个字符串，其他入口仍显示“只能信一部分”。
- 把“有真有假”“部分成立”“部分可证”当作可互换的装饰文案。
- 改动事实判定、分数或证据逻辑。
- 用更醒目的颜色或更大的胶囊掩盖表达问题。

## Evaluator

- 机器评：映射测试覆盖混合真假、单项部分成立和证据不足；仓库内用户可见路径不再出现“只能信一部分”。
- 机器评：`cd mvp && npm test`，并检查生产构建。
- 浏览器评：真实结果页的总判词、逐项判词与分享文案语义一致，直接回答仍先于解释和来源。
- 人评：标签读起来像事实判断，不像系统命令或短视频口吻；最终措辞由用户裁决。
