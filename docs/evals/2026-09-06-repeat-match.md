# 重复认出来：以前查过直接给

## Change

- 同一句话第二次进来，直接给旧结论，不跑全套核查。Evaluator：同一原句连查两次，第二次零新增模型和搜索调用，报告和日期一字不改。
- 换了说法但同一件事，给出旧的当线索，不自动继承结论。Evaluator：5 对换说法的重复，至少 4 对能翻出旧的，且都带打开旧的和重新查两个选择。
- 换了人物、日期，加了新链接新图片，不许悄悄沿用旧结论。Evaluator：人物变化、日期变化、加链接、加图片各一条，全部走到重新查，不直接给旧的。
- 本地没登录的和登录的各存各的。Evaluator：退出登录前后历史不串，存失败看得见。

## Not this

- 不做全库语义知识图谱，不跨用户汇总私人调查。
- 不改分数和名单分档。
- 不动部署脚本，不删旧代码目录。

## Evaluator

- 命令：根 `npm test`、根 `npm run build` 通过；生产目录 `npm test` 通过。
- 浏览器：完成一次真实调查，刷新重开旧案，检查网络零新增核查请求，旧报告带原日期。
- 人评：重复进来那一下，用户能不能一眼看懂这是以前查过的。
