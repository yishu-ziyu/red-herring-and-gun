## Change（要发生的行为）

### A. 进门不再有重复的「新查一条」

- 未登录空白输入态：首页**没有**任何「新查一条 / 新调查」按钮；品牌只是品牌名（不再是按钮，点了没有动作）。
- 正在看某次调查 / 旧结果时：出现回到空白输入的入口（点击后回到空白输入态）。

### B. 未登录首页不出现「模型设置」

- 未登录进门第一眼**看不到**「模型设置」（或任何模型 / provider / Agent 字样）。
- 登录后仍能从账号菜单进 `/settings/api-key`（入口不丢，只是不在进门第一眼）。

### C. 输入区下方加「查完大概长这样」示意块

- 位置：输入框与例子**下方**。
- 内容能分辨三件事：① 上面一句直接回答；② 下面有材料关系（支持 / 反驳）；③ 有一句片段感。
- 写明这是示意、不是真结果。
- 沿用现有浅色纸面与既有 token，不另起一套配色；证据关系用既有词表（支持 / 反驳 / 相关 / 尚缺 / 争议），不新造叫法。
- 片段必须沿用 PR #85 的诚实口径「检索片段（非逐字原文）」，不把检索片段写成逐字原文。

### D. 旧结果路径不断

- 从历史 / 完成态仍能回到空白输入（入口出现在结果态即可，不在首页重复）。

## Not this（明确不做）

- 不改结果页（PR #85 那套）。
- 不改后端、不改 `/api/*`、不改 schema。
- 不重排信息架构：不新增栏位、不改顶栏为左栏、不搬动画布。
- 不把「模型 / Agent / provider / 工具日志」写进未登录首页文案。
- 不新增产品叫法（不把「支持 / 反驳」改写成 mock 里的临时口语「帮 / 拆」）。
- 不理 `docs/tasks/.../assets` 里的一次性临时稿。

## 边界与已知差异（要如实交代，不算通过）

- 任务书 mock 的左栏形态来自旧壳；本地默认 `/` 是顶栏形态。E1–E8 取「语义一致」而非「像素一致」。
