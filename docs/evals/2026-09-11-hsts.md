# 验收：加 HSTS，把裸域名也兜进 HTTPS

日期 2026-09-11。用户裁决 A。

## 一句话任务

访客成功用 HTTPS 打开过一次之后，浏览器不再去试 HTTP。

## 背景（实测）

- `https://gun.yishuziyu.cn/` 正常（首页 / 接口 / 健康都 200，证书有效至 2026-11-02）。
- 裸 `http://gun.yishuziyu.cn/` 被阿里云备案拦截，稳定返回 **403**（`Server: Beaver`，重复 5 次里 4 次 403、1 次 301）。
- 阿里云侧 nginx **从未发过 HSTS**（早先看到的 `strict-transport-security` 是 Vercel 发的，不是我们的）。
- 所以：浏览器若不去试 HTTP 就没事，去试就会看到拦截页。

## Change

`scripts/configure-aliyun-static-nginx.sh`（443 vhost）：

- server 级加 `add_header Strict-Transport-Security "max-age=31536000" always;`。
- **同样一行加进那 4 个自带 `add_header` 的 location**（`= /index.html`、`= /sw.js`、`= /manifest.webmanifest`、`/assets/`）——nginx 的规则是 location 一旦有自己的 `add_header`，就不再继承 server 级的；不重复写，首页反而没有 HSTS。

不改：80 端口的跳转 server 块（那是 HTTP，HSTS 无意义）、裸 IP 的 vhost（对 IP 发 HSTS 无用且有害）。

## Not this

- 不改 `max-age` 之外的 HSTS 参数（不上 `includeSubDomains`、不上 `preload`）：本域名下还有 `bb.` 等其它子域，`includeSubDomains` 会把它们一起绑进 HTTPS，不在本次范围。
- 不改 `ops.sh`、不删 `mvp/`（T20 红线）。
- 不改应用代码。

## Evaluator

- **E1 首页带 HSTS**：`https://gun.yishuziyu.cn/` 响应含
  `Strict-Transport-Security: max-age=31536000`（改前为 `None`）。
- **E2 四个自带 add_header 的 location 都带**：`/`、`/sw.js`、`/manifest.webmanifest`、`/assets/<index-*.js>` 四条都能读到该头（E2 是为了防「只写 server 级、被 location 覆盖」这个已知陷阱）。
- **E3 缓存头没被挤掉**：同一批响应里 `Cache-Control` 仍在（外壳 `no-cache`、`/assets/` `immutable`）。
- **E4 其它 location 也有**：`/health`、`/api/models/list` 带 HSTS（它们没有自己的 add_header，走 server 级继承）。
- **E5 门禁**：`cd mvp && npm test` 零失败、`mvp build` exit 0、根 `npm test` 与 `npm run build` exit 0。
- **E6 线上可用性不回退**：`ops.sh public` 的 https / health / models 三条仍是 200。

人评项：

- **H1** 是否接受「HSTS 粘性一年」这个代价（以后若要临时用 HTTP 调试，访问过的浏览器会拒绝降级）。

## 执行记录（2026-09-11）

- **E1–E4 全过**（服务器侧直探，逐条读头）：

  | 路径 | HSTS | Cache-Control |
  |---|---|---|
  | `/` | `max-age=31536000` | `no-cache` |
  | `/sw.js` | `max-age=31536000` | `no-cache` |
  | `/manifest.webmanifest` | `max-age=31536000` | `no-cache` |
  | `/assets/index-Bs80gCnD.js` | `max-age=31536000` | `public, max-age=31536000, immutable` |
  | `/health` | `max-age=31536000` | （无） |
  | `/api/models/list` | `max-age=31536000` | （无） |

  改前这六条全是 `None`。E3 通过：缓存头没被 HSTS 挤掉。
- **E5 门禁**：mvp 103 文件 1170 过 / 1 跳过、mvp build exit 0；根 621 / 85 / 21 / 83、根 build exit 0。
- **E6 线上**：`System DNS: 121.89.90.68`；https / health / models 三条仍 200，无回退。
- **一处实现细节值得记下**：nginx 的 location 只要自己写了 `add_header`，就不再继承 server 级的 `add_header`。所以 HSTS 必须写成「server 级 1 处 + 那 4 个自带 Cache-Control 的 location 各 1 处」共 5 处；只写 server 级的话，恰好是最重要的首页会没有。这是本次改缓存头时差点踩到的坑。
- **未做**：`includeSubDomains` 与 `preload` 都没上（本域名下还有 `bb.` 等子域，`includeSubDomains` 会把它们一起绑进 HTTPS）。
