# 结果页是一篇回答 · 验收标准

- 日期：2026-09-11
- 用户原话：给了判断，又给了你的问题，又给了判断依据，顺序很怪。排版有问题，不要迁就项目。

## 先说清楚（不是验收，是判断）

完成态一直在把调查数据模型摊开：判断类别、命题条数、来源条数、原句、原子命题 01/02/03、关系分组。那是档案柜，不是一篇回答。人问的是一句话站不站得住。该先听到回答，再看见这句话里哪一段被标出来，再看见依据。原句在回答之后再以「你调查的说法」出现，等于答完又把问题拿回来问一遍。

「有对有错 · 命题 3 条」当开头，是内部词。好看与否：完成态仍是灰纸加发丝线，没有一页文章该有的停顿。本轮先把顺序做对，不假装已经好看。

## Change

完成态阅读顺序：

1. 直接回答（那句判断）
2. 必要的解释与边界（同一段气口，不是另一章）
3. 原来那句话，标出对应到哪些命题（文案是「这句话里」，不是「你调查的说法」）
4. 依据

「命题 3 条 / 来源 6 条」不出现在开头。「重新调查」「收起」不跟原句抢位置。

## Not this

- 不删命题、不编造关键依据清单。
- 不把原句从 DOM 里挪走（investigating → complete 同一节点）。
- 不把「有对有错」当第一句。
