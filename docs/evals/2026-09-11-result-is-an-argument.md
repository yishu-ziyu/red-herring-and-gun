# 结果页是一篇论证，不是档案柜 · 验收

- 日期：2026-09-11
- 用户：不要你点哪里改哪里；要从产品全栈想。不要把资料原句搬上来又不整理。

## 这件事是什么

人拿来一句话，要知道它站不站得住，以及凭什么。调查内核产出的是命题、角色、来源、片段、争点、缺口。那是档案。结果页的工作是用这些档案**写成论证**：先给判断，再按论点列出依据。每条依据是「这一点说明什么」，片段是收据，标题是出处。不是网页标题，也不是未整理的检索原句堆。

调查中可以按「找到了哪页」来读。完成态不行。

## Change

完成态：

1. 回答 + 解释 + 整句边界。
2. 依据按论点：有 finding 时，finding 是论点句；下面才是片段收据和出处。
3. 片段不作标题。出处 14px。
4. 争点只保留原因句。缺口只保留缺什么。命题边界只保留那句限制，不要「边界」表单标签。
5. 不要重复原句，不要 01/02/03 当骨架。

## Not this

- 不编 finding、不编片段。
- 不把档案字段改名就算整理。
- 不拆 investigating → complete 的证据 DOM 身份。
