# 审查看板首批修复：P0 来源条折叠 / P1 引文断行 / P2 案卷条堆叠 / P3 域名行内引用

Date: 2026-09-12
契约依据：`docs/reports/2026-09-12-page-audit/findings.md` + 看板 `review-board.html`。用户在审查看板上批准本批四项（P3 采纳推荐方案 A），P4/P5 留待裁决不在本批。

## Change

- **P0**：结论卡来源条（`.gp-hero-sources-strip`）在 ≤768px 视口默认折叠，只显示「已查验 N 个信息来源」一行触发器，点击展开/收起；桌面端默认展开不变。
- **P1**：结论断言中的引文（「…」）只在中文标点（、，。；：）处允许换行，不在词中间断行；移动端同步收敛结论卡水平内边距。
- **P2**：案卷条（`.gp-dossier-bar`）在 ≤600px 视口改为垂直堆叠：标题一行、控制按钮一行自动折行，不再左右挤压。
- **P3（方案 A）**：完成态证据条目的域名从右对齐悬浮改为行内引用：以灰字小字「— domain ↗」跟在被引文字之后，移动端桌面同一逻辑。
