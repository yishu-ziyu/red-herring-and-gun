# 验收标准：调查过程时空回溯案卷与交互式时间轴播放器

日期：2026-09-12
代号：`investigation-timeline-and-player`

## 背景与问题
用户指出：「把 30 秒的黑盒等待，拆解为 6 个可随时暂停、倒带的慢动作切片」，目前缺乏全流程真实展示与落地体验。
现有实现痛点：
1. 调查过程中活动流单向持续下刷，缺少暂停/慢读手段；
2. 调查完成（complete）瞬间将 ThinkingDisclosure、ActivityFeed 与角色工位粗暴卸载，导致完成态只剩一张孤立审判大卡，20+秒的思考与质询因果链路灰飞烟灭；
3. 评审沙盘此前为离散静态 Tab，缺乏流体连续的时间轴拖拽与播放回溯能力。

## 验收契约

### Change（用户必须能观察到的变更）
1. **完成态保留「调查案卷时空回溯轴」**：
   - 在结论大卡下提供一条轻巧优雅的 5 拍时间胶囊条（`0.0s 帖子原话` -> `1.4s 深度思考` -> `2.1s 命题拆解` -> `15.2s 证据交锋` -> `23.4s 终局裁决`）；
   - 支持一键展开/折叠「完整调查案卷与思考轨迹」，展开后完整保留历史 Thinking 与 ActivityFeed，不再在 complete 瞬间被抹除。
2. **调查中支持「慢读/暂停」**：
   - 调查进行中提供微控制胶囊，用户可暂停画面自动滚流进行慢读，再次点击恢复追赶直播。
3. **设计沙盘升级为「真实案例流体时间轴播放器」**：
   - 在 `design-lab.html` 沙盘中，将离散 Tab 升级为支持 **0.0s 至 23.4s 连续拖拽的 Scrubber 时间滑块**；
   - 提供「播放 (Play) / 暂停 (Pause) / 慢速 0.5x 慢放」控制；
   - 采用真实微博隔夜菜案例（`https://weibo.com/1749990115/P3bF9xY1z`），随着滑块拖动，界面物理呈现：收到帖文 -> 思考展开 -> 命题切片 -> 证据落座 -> 结论聚合。

### Not this（不符合要求的替代品）
1. 仅提供不可交互的静态截图或说明文字；
2. 在完成态直接强行恢复大块冗余界面遮挡结论大卡（必须采用优雅折叠与时间轴节点展开机制）；
3. 破坏已有的 1303 项测试或引入全属性 `transition: all`。

### Evaluator（验证尺度）
1. `npx vitest run src/goldenPath/goldenPath.test.tsx`: 全绿通过。
2. `npm test && cd apps && npm test`: 全绿通过。
3. `npm run build && cd apps && npm run build`: 双构建 Clean。
4. Playwright 真实浏览器实测 `http://127.0.0.1:5211/reports/design-lab.html`：时间轴拖拽、播放、暂停功能完好，无控制台报错。
5. 人评：用户可在浏览器中通过拖拽进度条观察 0s 到 23.4s 的全真流变。
