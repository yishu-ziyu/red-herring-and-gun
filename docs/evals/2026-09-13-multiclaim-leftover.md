# 2026-09-13 · 多主张结论与空尾巴

用户刚跑完一条「长城」长文调查：一段课文里既有站得住的事实（古代军事防御、很长、世界遗产），也有流传说法（太空肉眼可见）。结果页把整段打成「公开材料不支持这条说法」，标签写「证据反驳」，解释两句都是「尚未查清，未计入该判断」；下面一长串「检索预算未覆盖 / 模型未覆盖，待补证 / 还没有可展示的材料」空卡片刷屏。拆题把课文按句号切成十几条，检索名额只够前几条。

## Change

1. **结论第一句按条说。** 一段里有多条可核查主张时，完成态结论第一句必须说出哪几句站住、哪几句站不住（或尚缺），不能把整段打成「不支持这条说法」。标签不在「尚未查清」时写成「证据反驳」。
2. **完成态不刷空壳。** 「检索预算未覆盖」「模型未覆盖，待补证」「还没有可展示的材料」不在完成态成片展示。没查到的主张：要么折进一条「尚缺」用一句话说清「这些没查、所以结论没拿它们」，要么根本不生成空卡片。完成态 DOM 里这类空卡片为 0。
3. **拆题抽可核查断言。** 长课文不应按句号切成十几条再假装都是谣言。抽出可独立核查的断言（数量远少于句子数），背景叙述不单独成命题。

## Not this

- 不和正在进行的思考区诚实/阶段动效抢 `ThinkingDisclosure.tsx`、`WorkRoles` 入场动画、思考三步假打字。可以改拆题、报告、完成态命题列表。
- 不绕过检索上限语义：名额有限时诚实说没查完哪些，不是默默丢掉，也不是空卡片墙。
- 不改评分考试。不 commit。
- 不把「测试绿了」当成用户路径通了。
