# 事实查证案卷去 AI 味与视觉层级一致性重塑验收标准

- 日期：2026-09-17
- 目标：将 Golden Path 调查全流程从原有的“AI Agent 玩具化/控制台日志直铺”重塑为“严肃新闻调查案卷（Dossier）与严格视觉层级”风格；同时保留 4 个核心工作职责人物头像并接入真实后端流水线动效。

## Change（用户可见变更）

1. **4 个工作职责头像保留并注入真实后端逻辑动效（WorkRoles）**：
   - 保留原有的 4 个角色头像（`rumor-detector` 拆问题、`source-validator` 找出处、`fact-checker` 核语境、`report-composer` 作判断）。
   - 角色动效不再是无意义的循环或静态圆圈，而是与后端 SSE 真实事件严格联动：
     - 拆题阶段：`拆问题` 处于 active 状态；拆解出真实问题后右上角显示绿色完成徽章 `✓` 并汇报真实拆出要点数。
     - 检索阶段：`找出处` 激活雷达扫描波纹扩散（Radar Ripple），并根据后端带回的材料实时更新吸收计数徽章（如 `+N 篇`）。
     - 交叉比对与判定阶段：`核语境` 激活动态天平（Scale Balance）比对；`作判断` 激活定谳印章微动效。
     - 完成终态：4 位角色整齐归位，展示各自在本次调查中最终贡献的核查成果（如 `已拆解 N 项争议`、`已归档 M 份出处`、`已完成量效核对`、`已完成定谳出具`）。
2. **消灭冷门 NLP 术语与系统 Prompt 腔调**：
   - 界面上不再出现生硬的“命题”字样（如“这句话被拆成了这些命题”），全部改为符合自然语言与调查报告习惯的“核心核对要点”、“争议点逐项核实”。
   - 移除原先在完成态正中间裸露的 System Prompt / Guardrail 免责声明文字（如“回答只覆盖这些问题，不代表整份材料已获证实...”）。
3. **视觉层级重塑（Refactoring UI 纪律）**：
   - 消除完成态下的动线撕裂：移除卡片中间孤立的 `[查看已有依据]`、`[继续补查]` 按钮和突兀的灰框；核心裁定、结论总结与关键决定性证据卡片融为一体，形成具有高度权威感的出版级调查案卷。
   - 按钮层级明确：主按钮实心突出（通常唯一），次要操作边框弱化，辅助性操作纯文本链接，符合 Refactoring UI 层级原则。
   - 追问与深入补查自然融入报告底部，与阅读动线合拍。
4. **信源流去调试日志感**：
   - 调查中不再将 `找出处 带回材料：...`、`作判断 形成判断：...` 这类把 AI 内部 Tool Calls 当成 UI 的粗糙日志推给用户，升级为沉静专业的权威信源接入流。

## Not This（不计入的替代方案）

1. 不是简单地隐藏角色头像（用户已明确要求保留人物，并通过真实逻辑动效呈现）。
2. 不是写死定时器（setTimeout / setInterval）制造假轮询动画；动效必须与真实后端 phase / SSE 数据状态绑定。
3. 不是破坏已有的数据契约与快照格式（`InvestigationSnapshotV1`、`thread`、`caseId` 保持向后兼容）。
4. 不是只改 CSS 颜色，而不重构视觉层级与主次动线。

## Evaluator（验收尺度）

1. **机器项**：
   - `npm --prefix apps test` 全绿，所有现行契约（Issue A-E、线程、取消预算等）无回归。
   - `npm --prefix apps run build` 构建成功。
   - `npm test` 与 `npm run build` 全绿。
2. **人评项**：
   - 在 CMUx 真实预览中（桌面端 1280px 与移动端 390px）：
     - 调查过程中 4 位角色头像清晰呈现真实后端状态与计数，无悬浮假动画。
     - 完成态主界面呈现连贯的权威案卷视觉，无突兀灰框插队，无“命题”术语残留。
     - 底部追问自然衔接。
