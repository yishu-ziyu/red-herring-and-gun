# 2026-09-28 从首页进入调查时回到页顶

背景：2026-09-28 A/B 浏览器走查发现（Claude for Chrome 撞出，Ego 定量复现）：首页滚到「已完成的调查案例」后点「查看这次调查」，结果页沿用首页滚动位置。Ego 实测首页 scrollY=500 时点开，结论区「待核查说法」落在视口上方 -324px，用户第一眼看到的是中段逐条详情，看不到结论。案例区在首屏以下，真实用户几乎每次都会遇到。

## Change

- 页面从首页输入态切到调查态时，窗口回到页顶。覆盖：查看首页案例、提交新调查、从历史打开案例、刷新恢复进行中的调查。

## Not this

- 调查态内部不跳：追问开新轮、调查中保存后 `localId` 换成服务端 id、来源抽屉与活动流里的定位，都不回顶。
- 回首页不做额外滚动处理。
- 不改结论区布局、文案或动效。

## Evaluator

- 命令：`presentationIssueD.test.tsx` 新增断言：首页已滚动时点「查看这次调查」，`window.scrollTo` 以回顶参数被调用；修复前该断言失败，修复后通过。
- 命令：`cd apps && npm test` 0 失败；`npm run build` 绿；`git diff --check` 干净。
- 浏览器（Ego，可重复脚本）：本地首页滚动 500px 后点第一张案例「查看这次调查」，结果页 `scrollY` 为 0，「待核查说法」标题在视口内（top ≥ 0）。
- 浏览器（Claude for Chrome，真人式走查）：同一路径手动滚动后点击，截图第一屏能看到待核查说法与结论句。
- 人评：无。
