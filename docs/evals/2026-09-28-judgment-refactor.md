# 2026-09-28 整句判定重构：按主要主张定级

## 背景

同一句「大剂量维生素C有利于预防感冒。」在同一套代码上跑两次，得到两种错法：「不支持＋尚未查清＋证据不足」自相矛盾；拆题多出原句没说的「大剂量有明确阈值」，查不清后把整句拖成「证据不足」，而结论卡同时列着「关键依据：反驳」。

根因：整句判定没有单一决定点。模型先写整句判定，模型写完后还要经过约 10 道关卡改判定或改文字，前端徽章再单独推算一次；拆题只产出平铺命题，不记录哪条是主要主张。

业界参照：Snopes（primary elements / ancillary detail）、台湾事实查核中心（主要内容错误 / 部分错误 / 证据不足）、Decomposition Dilemmas（单句短主张拆题常有害）、FactLens（拆题不得编造）。对比页：`/tmp/rhg-plan/index.html`（产出后移入本目录）。

## 判定规则

「被反驳 / 被证实」只算能点开、且经过关系审核的出处。

| 主要主张（含并列主张） | 必要前提 | 背景细节 | 判定 |
|---|---|---|---|
| 任一被反驳 | 任意 | 任意 | 不能信（逐条写明其余部分状态） |
| 并列主张一个被证实、一个被反驳 | 任意 | 任意 | 有真有假 |
| 全部被证实 | 全部被证实 | 无被反驳 | 能信 |
| 全部被证实 | 全部被证实 | 有被反驳 | 部分成立 |
| 全部被证实 | 有被反驳 | 任意 | 有真有假 |
| 全部被证实 | 有查不清 | 任意 | 证据不足 |
| 查不清 | 任意 | 任意 | 证据不足 |
| 证据互相冲突 | 任意 | 任意 | 有争议 |

## Change

- 拆题产出：每条命题标注角色（主要主张 / 必要前提 / 背景细节），每条能在原句中找到对应片段；单句短主张不拆。
- 整句判定由一个纯函数按上表得出；首句、逐条说明、徽章都读这一个结果。
- 被新函数取代的关卡：先把它防的失败写成新函数的测试并通过，再删除。

## 实现（2026-09-29，用户批准恢复整句判定重构）

- 规则表只在一处：`apps/server/src/domain/verdict.ts` 的 `decideSentenceVerdict`（纯函数，不引用任何外部模块）。行 1–8 与评分规则 1–6（出处说错、夸大、权威冲突、没有公开记录的传言、一截属实一截被反驳、「已证明」对「有效果」）都在它的测试里逐条有用例。评测 `eval/answerBenchLabel.ts` 只把标注词汇翻译过来调用它，产品与评测不会各有一份规则。
- 拆题：每条命题记录 `role`（main / premise / background）、`issuer`（是不是在说发文机关或出处）、`span`（原句里对应的那一截，逐字）。代码检查在 `claimAtom/roles.ts`：span 对不上原句的命题丢掉、短单句不拆、只含「不该 / 应该」的价值判断标立场型、整句是立场而模型一条命题都没给时补一条立场型命题。
- 每部分的状态在 `sentenceVerdict.standingOf`：只认方向一致、能点开的出处；夸大按被反驳；有争议要两边都有出处；只有支持、没有任何反驳的 partial 按被证实。
- 首句、`verdictType`、徽章、摘要、正文、快照徽章都由同一个决定推出（`sentenceVerdict.applySentenceVerdict`），不再读模型写的整句文字。新增快照徽章「有争议」（`InvestigationJudgment` 加 `disputed`，`packages/core` 与 `apps/server` 两份镜像同改）。
- 被规则表取代并已删除的关卡：原子级守门（mixedGuard）、早收权门、短谣通道对 verdictType 的直接改写、终收权门、收权后重建文字（`applyConclusionGate` / `needsConstrainedConclusion` / `repairGatedConclusion` / `renderVerdictConclusion`）、`deriveOverallVerdict`。它们各自防的失败先写成对规则表与收尾链的测试（`domain/verdict.test.ts`、`sentenceVerdict.test.ts`、`casePipeline/finalizeReport.verdict.test.ts`），通过之后才删关卡；对应的旧测试随关卡一起删除。
- 收尾链现在的顺序见 `casePipeline/finalizeReport.ts` 头注释：整句判定只在「先行（只给公式分用）」与「终局（死链剔除之后，写结论文字）」两处，是同一个纯函数的两次求值。
