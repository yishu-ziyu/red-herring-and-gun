## 评分规则（用户 2026-09-29 裁决）

题库改为「分截 + 原文引用」：每截配一句从出处逐字抄下的原文，代码回查原文确实包含该句；整句判定由 9-28 判定表推出。人只裁规则和两份独立标注的分歧，不逐条判真假。

1. 内容属实、只说错了发文机关或出处（例：生育津贴直接发到个人卡属实，发文的是国家医保局，原句说成人社部）→ **能信**，答案必须写明实际发文机关。这条覆盖判定表「背景细节有被反驳 → 部分成立」一行，仅限机关或出处说错；其他背景细节被反驳仍按原表。
2. 把个别现象说成普遍或说大了（例：个别运动员自带床垫，「自带 300 多个空调」不实）→ **不能信**，答案写明属实的那一截。
3. 权威来源之间互相矛盾（例：维生素 C 对普通人与剧烈运动人群结论不同）→ 边界题，不按单一标签评分；点明在什么人群或条件下成立、什么情况下不成立，且没有把话说满，即算对。
4. 按常理不会有公开记录的传言（例：公司下周被收购、物业费已定涨一倍）→ **证据不足**，且须说明缺什么、该去哪里核实（公告、业委会通知等）；判「不能信」算错。
5. 一句话里有一截属实（如实施日期）、真正让人信的那一截被反驳（如「旧车一律淘汰」「所有人干到 65 岁」）→ **不能信**，答案写明属实的那一截。（用户 2026-09-29 裁决）
6. 原句断言「已经证明」某功效，权威来源明确说该功效未经证实 → 该截**被反驳**；原句只说「有效果」而来源只说「未证实」→ **查不到**。（用户 2026-09-29 裁决）
