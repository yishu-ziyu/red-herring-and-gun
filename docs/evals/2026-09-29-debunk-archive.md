# 2026-09-29 本地辟谣档案：先查档案，再搜索

## 为什么

产品最大的缺口是自己手里没有权威辟谣数据，每次调查都要现搜。中国互联网联合辟谣平台（piyao.org.cn）已经把各部门、各地网信辟谣按日期发布出来，可以按站点、按日期整批存到本地，再做一个确定性的查找函数。

## Change

1. `apps/server/src/lib/debunkArchive/crawl.ts`：命令行爬取 piyao.org.cn。先读栏目页，从栏目页里找到列表数据文件（`ds_<32位十六进制>.json`，一次给出该栏目全部条目与发布日期），再逐篇抓 `/YYYYMMDD/<hex>/c.html`。每秒不超过 1 次请求，User-Agent 写明用途，已抓过的跳过（可续跑），数量上限、时间上限、日期范围都可配。只按站点栏目和日期范围导入。
2. 抽取：每篇存 url、标题、发布日期、原始发布方（「来源：」）、谣言说法（可多条）、结论措辞、2–5 句原文关键句、全文、文章类型（单条 / 汇总 / 其他）。JSONL 存 `data/debunk-archive/articles.jsonl`，原始网页存 `data/debunk-archive/raw/`。`data/debunk-archive/` 写进 `.gitignore`，不提交第三方内容。
3. `apps/server/src/lib/debunkArchive/index.ts`：启动时（首次调用时）把 JSONL 建成内存索引，`lookupArchive(claim, opts)` 返回 `{url,title,publishDate,publisher,matchedStatement,keySentences,score,differsOn,kind}`。方法：字符二元组 BM25，只索引谣言说法（单条文章再加标题；汇总文章不索引标题），不调模型，不用同义词。
4. `differsOn`：查询里有、但命中的说法里没有的数字、日期、地名；有差异时分数按差异个数衰减。

## Not this

- 不接进调查管线（这次只交档案和查找函数，接入另议）。
- 不提交任何抓取来的内容，不提交 `data/debunk-archive/`。
- 不按 `answerBench.json` 的题目搜索或挑选文章导入；基准只用来量档案，不能塑造档案。爬取代码里没有任何「按说法搜」的入口。
- 不做模型排序、不做同义词表、不做繁简转换。
- 不判断「结论过期」：只返回发布日期，交给调用方。

## 先写会怎么坏

| 坏法 | 后果 | 挡法 | 挡不住的部分 |
|---|---|---|---|
| 汇总页（如 CNR 汇总页标题与内容无关，issue #90）的标题被当成每条说法的标题 | 查到不相干的「命中」 | 汇总文章不索引标题；每条说法单独成条；测试：汇总页产出多条说法 | 汇总页只有图片、正文没有说法时只剩标题里的说法 |
| 相似但不同的说法：换了人、日期、地点、数字 | 把「另一件事的辟谣」当成这一件的辟谣 | `differsOn` 列出数字/日期/地名差异并压分；测试覆盖 | 人名、机构名不同不会被标出，只靠覆盖率压分 |
| 结论过时 | 早年辟谣的事后来变成事实 | 返回 `publishDate` | 不判断，由调用方决定 |
| 抽取抓到导航、责任编辑、版权文字 | 关键句是垃圾 | 只取正文 `#detailContent`，去模板句；测试用样例网页 | 站点改版后需要重抽（原始网页已存，可离线重抽） |
| 非辟谣文章（健康科普、通报）被当成辟谣 | 「没有说法」的文章命中 | 抽不出说法的文章类型记为「其他」，不进索引 | 标题带问号的科普文章可能被当成说法 |
| 列表接口有条数上限 | 早年文章覆盖不到 | 报告实际日期范围，不假装覆盖 | 联动要闻只到 2025-07，工作动态到 2022-08 |
| 爬得太快或被封 | 站点受扰 | 每秒 1 次、UA 明示、可续跑、遇 429/5xx 退避 | — |

## Evaluator

| 项 | 怎么量 | 类型 |
|---|---|---|
| 抽取：样例网页（自写、精简，非整页第三方内容）得到正确标题、日期、来源、说法、结论、关键句 | `cd apps && npx vitest run server/src/lib/debunkArchive` | 命令 |
| 汇总页产出多条说法，且不用汇总页标题当每条的标题 | 同上 | 命令 |
| 查找排序：同一说法排第一；换地名/日期/数字时 `differsOn` 非空且分数低于原说法 | 同上 | 命令 |
| 速度：全量档案单次查询 < 50ms | 真实档案上跑 200 次取最大值（脚本输出） | 命令 |
| 服务端类型检查 | `cd apps/server && npx tsc --noEmit` | 命令 |
| 真实爬取：篇数、日期范围、20 篇随机抽样人工看抽取是否正确 | 爬完后抽样 | 人评 |
| 基准 40 条的 top-1 命中率（仅测量，不据此改档案） | 脚本对 `answerBench.json` 每条查一次，人工判断是否同一说法 | 人评 |
| `.gitignore` 生效 | `git status` 里看不到 `data/debunk-archive/` | 命令 |
