# 一份正式判断，统一调查与结果页

## Change

用户已确认全部判断与三步顺序：收口当前版本并提交；重写核查到报告链路；接入已确认原型。原工作区与线上保持不变，继续使用rewrite/evidence-first。

1. 根验证命令指向apps生产实现；离线合同门禁和真实模型质量评测明确分开，不把假模型得分当质量。不再以冻结packages作为生产完成条件。
2. 每条命题只有一份正式判定，引用原文与适用范围绑定。模型继续写报告，不能另改判词。默认一次核查，只有具体缺口/冲突且获得新材料时重判；合并重复补查/审计入口。
3. 复用已有存储，保存满足原文要求的公共证据；摘要旧条目不能阻止搜索。保留私人历史与公开证据边界，不另建数据库。
4. 完成页按既定原型展示原句、判断、逐条已核原文、来源及必要边界；其余材料/调查经历折叠。没有实际缺口就不生成推荐追问，保留自由输入。调查角色/动态/思考展示不删除。

## Not this

不扩功能入口，不更换模型/搜索供应商，不改账户权限，不发布，不在每次改动后跑40题，不造通用评测平台。冻结packages仅作历史保留，必要镜像仍守一致性。

## Evaluator

- 根npm test/npm run build执行apps代码；npm run eval:gate直接运行生产管线固定合同用例并明确标注离线，不需要API密钥；真实质量评测独立命令，缺基线不得写成通过。
- 固定反例覆盖属实、不属实、真假混合、范围夸大、来源冲突、仅摘要、原文无法取得、同名异人、存档死链、历史/分享复现。没有新增证据时不再重复核查，同次结果总答/分条/保存/分享读同一判定。
- 新旧复用记录都能读取；旧摘要按缺正文处理，带可核正文的新记录可复用；私人说法不误写共享库。
- 真实浏览器：充电宝、苏打水、已有档案的一条说法；能直接看到对应引句并打开出处，查不到时不输出肯定解释；旧历史、分享、中断路径仍可用。桌面和390px，无横向溢出。
- 记录真实模型调用和耗时，只比较同一输入与代码状态，不承诺未实测提速。
- 检查diff，删除已替代的后处理与重复入口，统计生产/测试净变化。只提交属于本任务的文件；不合并/部署。
