# 结果页 B3 原型（参考 rss.qiaomu.ai）

这是「红鲱鱼与枪」核查结果页的一个**静态设计原型**，**还没有接入 `apps/`**。页面不调接口，所有文字都取自开发 fixture `?fixture=complete`（隔夜菜致癌案例），左侧历史记录用的是首页的真实案例。

设计语言参考的是 [rss.qiaomu.ai](https://rss.qiaomu.ai/)（QMReader），以下都是从它的 CSS 原样取的：
- 颜色 token：`#f7f7f6 / #fff / #f2f2f1 / #e2e2df`，文字 `#171717 / #4f4f4a / #8a8a84`，黑色主按钮
- 三栏宽度：侧栏 232、列表 320、右侧抽屉 304
- 控件：10px 圆角卡片、34px 控件高度
- 字重 780–820 的粗标题；阅读正文 16.5px / 1.88
- 动效曲线 `cubic-bezier(.23,1,.32,1)`

## 怎么打开

直接用浏览器打开 `B3.html` 就行，不需要起服务。也可以在本目录运行 `python3 -m http.server`，再访问 `http://localhost:8000/B3.html`。宽度在 720px 以下会切到移动端布局。

## 能交互的部分

- **选中命题**：点中间列表里的命题，或点标题下方的结论分段条，阅读区会平滑滚到对应卡片并短暂高亮；滚动阅读区时，列表的选中状态会跟着走。
- **右侧抽屉**：默认收起。点右上角「来源 6」或「查看已有依据」会从右侧滑出「来源」页；点「继续补查」会打开「追问」页。点推荐追问，它会填入下方输入框。按 Esc 可关闭。
- **抽屉与列表互让**：屏宽小于 1680 时，抽屉打开会让中间列表收起，所以阅读区宽度基本不变，正文不会重排。
- **视图切换**：「判断与依据」和「调查案卷」之间可以切换。
- **移动端**：菜单按钮滑出侧栏，「来源」按钮滑出抽屉；首屏先看到判断。

## 已知缺口

- **没有功能的控件**：「复制结论简报」「重新调查」「新调查」「调整核查重点」、历史记录各条、「登录」和「追问」发送按钮。
- **抽屉和列表不能同时显示**：1440 宽下打开抽屉时，中间列表会隐藏。
- **移动端标题**：判断标题有 3 行。
- **折行**：1440 宽下，摘要句在「一定安全」处折行。
- **字体**：本原型用 Noto Sans SC 代替 qiaomu 的 PingFang / SF，粗字重观感略有差异。
- **数据**：都是 fixture 写死的，没有真实数据流，也没有加载、出错、进行中等状态。
- **粘贴版**：`B3-paste.html` 没有悬停和动效，也只有抽屉收起这一个状态。
