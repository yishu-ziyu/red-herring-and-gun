# 第 15 章 · 智能体间通信（A2A）

## 裁决
done-in-our-form

## 分数
5 / 5

## 书要解决什么
一件复杂事不要交给一个模型从头演到尾。
专门角色之间要交接机器能读的中间结果，才能分头做事再收束。
书把这件事做成跨进程、跨厂商的 Google A2A：公开发现、HTTP JSON-RPC、远端不透明。

## 我们有没有
有但形状不同。
生产是同进程、代码定顺序的 JSON 交接，不是跨厂协议。
对应路径：`mvp/server/src/lib/casePipeline/runCasePipeline.ts` 按 Phase 叫 `rumor_detector` → 自证 → 按条检索 → `fact_checker` / `source_validator` → 报告。
对应路径：`mvp/server/src/lib/agentConfigs.ts` 的 `HandoffStep` 与 `buildAgentInput`：下一步只拿自己需要的字段，不是整段聊天记录。
拆题交给核查的是 `claimAtoms`。
核查交给报告的是 `subclaimVerdicts`、来源和缺口。
对应路径：`mvp/server/src/handlers.ts` 的 `makeRunAgent`：把 `buildAgentInput` 的 JSON 写成 `userContent`。
同一函数把 `atomSearchBundle.forAgent` 注入 `fact_checker` / `report_composer` 的 `atomSearches`。
对应路径：`mvp/server/src/lib/atomSearch.ts` 的 `forAgent`：每条判断带可点开的 `url` / `title` / `snippet`。
报告再收一包：`handlers.ts` 的 `buildReportEvidenceInputs` 把检索摘要、核查发现、信源审计交给 `report_composer`。
FactChecker 提示写明：只根据 `search360` / `atomSearches` 和前序输出核查，模型记忆不是核查；没有可点开网址不得写成真或假。
ReportComposer 提示写明：不得编造输入里没有的原子，来源只能引用输入里出现过的。
对应路径：`mvp/server/src/lib/reportAssembly/assembleFinalReport.ts` 用前序 JSON 和检索包收束用户看见的能信 / 不能信。
冲突时第二模型也只拿该条判断和两侧来源：`mvp/server/src/lib/crossExam/crossExam.ts`。
生产拆题 schema 没有 `handoffTargets`：谁下一步由管线定，模型不能点名下一个角色。
赛题 10% 要的是「Agent 之间传核查材料，不是演戏」；上述路径传的是原子、网址、逐条判词。

Google A2A 协议：没有。
仓库未找到 `AgentCard`、`/.well-known/agent.json`、`sendTask` / `tasks/send`、A2A SDK。
`mvp/server/package.json` 无 A2A 依赖。
`handlers.ts` 里的 JSON-RPC 是 AnySearch 检索工具调用，不是智能体间协议。
`mvp/server/src/lib/mixerMcp.ts` 是 MCP；书自己把 MCP 和 A2A 分开。
跨厂发现、远端不透明、mTLS、Webhook：故意不做。
依据：`docs/PRODUCT_SPEC.md` 第三节（多 Agent 传核查材料）、第六节（不是编排框架演示、不是自治 Agent）。
依据：`docs/adr/ADR-002-deepagents-evaluation.md`、`docs/adr/ADR-003-production-case-pipeline.md`。
书里「远端不透明、客户端不必知道内部」会挡住来源核对，和生产的判决纪律冲突。
赛题没有「必须接 Google A2A」这一栏。
`mvp/src/lib/agentRuntime/handoffPacket.ts` 是 eval / 本地实验床上的压缩包，不是生产真相。

## 对能信/不能信的意义
拆题交出可核对的判断，检索交出能点开的网址，核查对着这些网址写逐条真假，报告只能用这些材料收束。
没有网址就不能写成能信或不能信；立场型判断不进真假清单，报告写「立场型 / 不适用真/假判断」。
不接跨厂协议，用户看见的结论仍绑在本管线的来源上，不会变成远端说一句就算。

## 缺口
无。
不接 Google A2A 不是欠债。
不要为协议而协议。
