## 书要解决什么
智能体不是一次本地测试过了就永远准。
要对着标准答案量结论、量步骤、发现漂了或异常，才能拦住错结论进入用户看见的判断。
书还推 LLM 当评委、轨迹精确对照、A/B、token 账本、ADK、承包商合约；对本产品后几项不是欠债。

## 对能信/不能信的意义
用户看见的能信 / 不能信 / 只能信一部分 / 还查不清，必须能被复盘：哪一截拆错、有没有来源、是不是被标成「立场型 / 不适用真/假判断」所以没查。
评测抓不住这三类，门禁仍可能绿，用户仍拿到错的整句结论。
`/health` 只能告诉你服务没挂，不能告诉你这句话该不该信。

## 缺口
1. 半真半假拆错抓不全。
整句期望 mixed 能挡住「整句打成不能信」，挡不住「真截判假、假截判真、整句仍是 mixed」。
`mixed_misleading` → `false` 不算幻觉，门禁也不看 `hallucinationRate`。
`score.test.ts` 没有把 RUMOR-011 形态钉成失败用例。
伤害：用户看见整句「只能信一部分」，但哪一截能信是反的。

2. 无证据判假抓不住。
golden 没有「应还查不清」的案。
零绑定 URL 写成 `false`，`scoreCase` 仍可 `verdictCorrect`（golden 也是 false 时还会 overallPass）。
TINY-005 / TINY-006 期望 `false`：模型遵守「没搜到不等于假」写成 unverified，评测反而判错。
伤害：空检索被写成「不能信」；或者敢说查不清的纪律被门禁惩罚。

3. 类型标错导致不检索：eval 案例不存在。
能核对的流传说法被标 `verifiable: false` 后，代码照做不搜，报告只写「立场型 / 不适用真/假判断」。
生产评测不看拆题标签，也不要求 `atomsSearched` 非空。
伤害：该查的说法没被查，用户当成不适用真假。
这是说明书已承认的已知不满，评测没有把它变成会红的案例。

4. 门禁与基线护不住上面三条。
`baseline.json` 还是 14 条、失败列表残缺、无 LOOP 指标。
G1 翻案率只观测。
`eval:gate` 未进 CI。
伤害：漏查和乱判可以在「门禁通过」下进入用户报告。

## 方案（仅 partial 或 missing-and-needed）
Goal:
生产评测必须能单独抓住三类错：半真半假拆反、零来源写成不能信、能核对的说法被标立场所以没查。
Hard bar:
1. 放入 RUMOR-011 形态案：原子 A 期望 true 且须有绑定 URL，原子 B 期望 false；A/B 对调或整句打成 false 时，`scoreCase.overallPass === false`。
2. 放入期望 `unverified` 的案（检索允许 0 URL）：实际 `false` 或 `true` 时 `hallucinationDetected === true` 且不得 overallPass；实际 `unverified` 且零绑定 URL 时通过。
3. 放入类型闸案：原句是可核对的流传说法，期望该条 `verifiable === true` 且被检索；若拆题标成价值/规范、`atomsSearched` 不含该条、报告只剩「立场型 / 不适用真/假判断」，评测失败。
4. `mvp/server/eval/score.test.ts` 为以上三案各有一条失败钉死；`eval:gate` 把 `hallucinationRate` 与这三类失败计入门禁。
改哪些文件:
`mvp/server/eval/golden.ts`：加 mixed 按条期望、unverified 案、类型闸 mustSearch 案；TINY 里搜不到的改为期望 unverified，或注明「有来源才许 false」。
`mvp/server/eval/score.ts`：按条判词、零 URL 禁止 false/true、期望检索却未搜视为失败；`mixed_misleading` → `false` 记入幻觉或独立陷阱项。
`mvp/server/eval/score.test.ts`：覆盖上述三条，不只测 repeats 与 loop 观测。
`mvp/server/eval/run.ts`：门禁纳入幻觉率与三类陷阱；TINY 的 `searchedShare` / `boundUrlShare` 对期望检索的案变成硬条件。
`mvp/server/eval/baseline.json`：用含新案的全量跑重写，禁止 14 条旧聚合继续当门禁。
明确不做:
不改生产管线，不在本方案里给类型闸加第二意见（说明书未拍板）。
不引入 LLM 当评委给「有用性」打分。
不上 Google ADK、LangGraph eval、承包商合约、A/B 平台、token 成本看板。
不把 AgentRuntime 那份 14 条前端 golden 当成生产门禁。
不把 `/health` 与 `/api/models/health` 当成判决质量监控。
