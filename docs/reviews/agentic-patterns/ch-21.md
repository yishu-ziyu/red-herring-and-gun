# 第 21 章 · 探索和发现

## 裁决
done-in-our-form

## 分数
5 / 5

## 书要解决什么
已有知识和第一轮问法不够时，系统要主动换角度找新材料，不能只在预写答案里打转。
书把这件事做成开放发现：自己立假说、自己辩论、自己做实验，去找「还不知道自己不知道什么」。
示例是科研助手和游戏搜新策略，目标是永远长出新知识。

## 我们有没有
有但形状不同。
核查里的探索只做一件事：换问法找原始出处。
不是开放浏览，不是立新假说，不是永远写出一份研究报告。

对应路径：`mvp/server/src/lib/evidencePursuit/evidencePursuit.ts` 的 `buildQueryPortfolio` 为每条可核查判断生成六路问法（exact / entity / primary / temporal / refutation / alternative）。
同一文件的 `assessEvidenceGap` 看还缺原始来源、反证、时间、当事方、独立来源。
`queriesForGap` 按缺口选下一问。
`computeInformationGain` 把同站或近标题转载的增益视为约 0。
`GAIN_STOP_THRESHOLD`（0.18）以上才算够了可停。

对应路径：`mvp/server/src/lib/atomSearchQuery.ts` 的 `buildAtomSearchQueries` 在首轮从组合里实搜 2–3 路。
`mergeParallelSearchPayloads` 用 `fuseByRrf` 融合多路问法的结果。

对应路径：`mvp/server/src/lib/evidenceLoop/evidenceLoop.ts` 的 `runEvidenceLoop` 才写下 hops。
触发只有 unverified，或支撑与反证同时非空。
模型只改写检索词，提示写明不判断真假；失败回退 `queriesForGap` / `fallbackRewriteQueries`。
`extractSources` 丢掉没有 `http` / `https` 网址的条目。
停因只有 `evidence-found` / `no-new-evidence` / `rewrite-empty` / `search-failed`。
笼子写在代码里：目标原子最多 3、每 pass 最多 2 轮、每轮最多 2 条查询。
`mvp/server/src/lib/casePipeline/runCasePipeline.ts` 的 Phase 2a 最多再续 1 个 pass，总轮不超过 4。

对应路径：同一文件把 hops 写入 `finalReport.evidencePursuit`。
没有有效新证据不重判。
重判后仍无证据就停，判词可以继续是未证实。
`mvp/server/src/handlers.ts` 把每一跳和四类停因以「证据追索」发出。
`mvp/src/lib/evidencePursuitUi.ts` 与 `mvp/src/components/v3/phases/mission/MissionPursuitFold.tsx`、`mvp/src/components/v3/phases/ResultView.tsx` 让用户回看目标、搜了什么、原始来源或转载或没有、还缺什么。
干净命题不触发循环，也就没有 hops。
立场型判断不发起证真证伪检索，报告写「立场型 / 不适用真/假判断」，没有探索 hops。

依据：`docs/adr/ADR-004-evidence-sufficiency-loop.md`、`docs/adr/ADR-005-evidence-pursuit-search-policy.md`、`docs/PRODUCT_SPEC.md` 第四节 4a 与第八节。

故意不做：书里的 Google 协同科学家（自己生成假说、辩论、Elo 排名、设计实验）、Agent Laboratory（文献综述、跑实验、写论文、往 AgentRxiv 共享）。
无界探索会编引用，也不敢说查不清。
说明书把「Deep Research 系（自治浏览 · 永远有答案）」标成低纪律对照物。
依据：`docs/PRODUCT_SPEC.md` 第六节「不是自治 Agent」、第八节定位图；`docs/adr/ADR-002-deepagents-evaluation.md` 不迁 DeepAgents；ADR-005「不做 LLM 自治决定下一跳」「禁止第二套 Search Agent」。

故意不做：`mvp/docs/RECURSIVE_EVIDENCE_SEARCH_PLAN.md` 里「用户点 frontier 再扩一层」的画布递归搜索。
该文还在仓库，不是生产路径。
P0 只回收了 frontier 思想：改成系统按证据缺口生成下一问，见 ADR-004 决策第 5 条与「不做」。
`mvp/src/lib/agentExpansion.ts` 的 `requestRecursiveSearch` 与 `/api/agent/recursive-search` 不进 Case Pipeline。

故意不做：去发现原句没说过的新判断。
`mvp/server/src/lib/claimAtom/selfProof.ts` 的自证闸门丢掉原句没有的原子，探索不得长出新指控。

## 对能信/不能信的意义
第一轮没命中，不会立刻写成「不能信」；代码换问法找原始出处或反证，仍没有就说「还查不清」。
每一跳都有预算和停因，不会开放浏览到编出网址。
用户回看的是「还缺什么 → 搜了什么 → 原始来源或转载或没有」，不是一份永远写得满的研究报告。

## 缺口
无。
本章不建议补开放浏览、假说锦标赛或用户手选 frontier。
