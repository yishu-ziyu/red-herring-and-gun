## status
implement

## 独立审查意见
生产开案不读 searchAccepted、检索不读记忆，成立。
原方案过满：不要改 buildAtomSearchQueries 主配方。
写入侧 effectiveQueries 常是原句，照单复用等于没学。
报告引用不得来自旧案快照。

## Goal
同类说法第二次进来时，首轮实搜先插入上次已确认的问法。
supportingSources 只绑本案新检索到的 URL。

## Hard bar
accepted 的 search_strategy 含历史问法时，buildQueriesWithReuse 对同义改写插入该问法，长度 ≤ 3。
proposed 不进种子，无命中时输出等于配方。
旧案 URL 与判词不得进种子。
bind 后 supportingSources 只有本案 URL。

## 改哪些文件
新建 `mvp/server/src/lib/queryReuse.ts`：extractReusableQueries、mergeReuseSeeds、buildQueriesWithReuse。
改 `memoryCandidateGenerator.ts`：effectiveQueries 收 supportQuery/contradictQuery 与 hops 里打中的 query。
接线：`handlers.ts` 只许改 retrieveAtomSources / makeSearchOneAtom：开案一次 searchAccepted，有 hits 用 buildQueriesWithReuse。
不得改 atomSearchQuery.ts 的 buildAtomSearchQueries 函数体。
新建 queryReuse.test.ts。
