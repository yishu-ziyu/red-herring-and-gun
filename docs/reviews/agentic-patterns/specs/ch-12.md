## 独立审查意见
核查模型未完成时，isOnTopicDebunk 会把 factCheckResult 写成 false，测例还锁死了这个错误。
boundTinyRumorVerdict 在核查成功时压 false 是另一条路，本章不许动。
source_validator 失败也会把像辟谣 URL 写入 verifiedSources。

## Goal
模型未完成时不得因「像辟谣」写成不能信。
factCheckResult 与 sourceReliability 必须是 unverified。
URL 仍可进来源栏，不算已经查完。

## Hard bar
fact_checker 与 source_validator 抛错，检索有辟谣链接 → factCheckResult unverified，faceVerdict「还查不清」，counterEvidence 空。
旧测例「失败仍给出不能信」必须改写或删除。
