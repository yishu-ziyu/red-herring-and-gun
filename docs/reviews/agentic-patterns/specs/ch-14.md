# 第 14 章施工规范 · 知识检索（RAG）

## status
implement

## 独立审查意见
按原子搜公开页、related-only 不算有据，成立。
漏：检索为空时 `allowedUrls = null`，幻觉 URL 会留下。
bind 用 `...v` 留下 true/false。结果页会显示能信/不能信。
整句守门留给第 18 章。

## Goal
`bindAtomEvidenceToVerdicts` 返回后，没有该原子本轮检索里出现过的 http(s) URL 时，true/false 必须变成 unverified。
仅 related-only 不能把该条留在真或假。
该原子检索为空时，模型自写 URL 必须剥掉。

## Hard bar
空检索 + 幻觉 URL + verdict true → 无 URL，verdict unverified，evidenceGaps 含待补证。
false + 空支撑反证 + 检索有 URL → sourcesRelatedOnly true，verdict unverified。
true + 检索里真实 URL → 仍 true。
partial / exaggerated 走 related-only 时判词不变。
旧的剥 [n]、填充、空检索缺口测例仍过。

## 改哪些文件
`mvp/server/src/lib/atomSearch.ts` 的 `bindAtomEvidenceToVerdicts`：始终传入该原子 known 集合，空集合不是 null。
related-only 或支撑反证都无 http(s) 且 verdict 为 true/false → unverified，补「待补证」。
`mvp/server/src/lib/atomSearch.test.ts`：按 Hard bar 补测。
不改 selectAtomsToSearch、retrieveForAtoms、buildAtomSearchBundle。
