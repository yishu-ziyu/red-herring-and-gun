## 独立审查意见

## Goal
merge 之后无 http(s) 的 true/false 必须 unverified。
derive 不得把无据之真收成 true，不得让无据之假单独返回 false。
reviewer 整句 true/false 且没有非 related-only 绑定 URL 时收成 unverified。
短谣 boundTiny 例外保留。

## Hard bar
merge：true 且 searchSources=[] → unverified。
merge：false 且 URL 被剥光 → unverified。
derive：两条无来源 false → null。
derive：有据 true + 有据 false → partial。
derive：单独一条有据 false → false。
reviewer：true 且无有据 URL → unverified。
reviewer：false 仅 related-only 且对题辟谣 → 仍 false（boundTiny）。
