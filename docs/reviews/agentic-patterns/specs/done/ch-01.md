## orchestrate 是否走 runCasePipeline
Express 生产入口走。
`mvp/server/src/index.ts` 把 `POST /api/agent/orchestrate` 接到 `handlers.orchestrateHandler`，把 `POST /api/agent/orchestrate-stream` 接到 `handlers.orchestrateStreamHandler`。
`mvp/server/src/handlers.ts` 里两个函数都 `await runCasePipeline({...})`（约 1036、1211 行）。
Vite 中间件不走。
`mvp/vite.config.ts` 同名两个函数都调 `createAgentRuntime().runCase`，不调 `runCasePipeline`。
与 ADR-003 一致：生产是 Case Pipeline，Vite / AgentRuntime 是 Dev/eval。
