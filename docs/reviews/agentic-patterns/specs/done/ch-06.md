## 改了什么
只改 `mvp/server/src/lib/atomSearchQuery.ts` 的 `buildAtomSearchQueries` 选路，以及对应测试。
截图 / P图 / 配图 / 原图 / 聊天记录：插入「原图 出处 首发」。
统计数字（百分比、万亿、例、GDP/同比/确诊后跟数字）：插入「公报 原始数据」。
日期和版本号不算统计。
引号内 4–40 字：插入「原话 语境」。
拼装仍是 extras → exact → 截图 → 引语 → 数字 → second → third → temporal，封顶 2 或 3。
函数签名仍是 `buildAtomSearchQueries(atom: string): string[]`。
