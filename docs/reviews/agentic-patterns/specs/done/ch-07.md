## cross exam 分歧是否降分不重写判词
是。
用例：`cross exam：证据冲突触发第二模型复核，分歧降分不重写判词（G3）`。
主判 `factCheckResult` 仍是 `true`。
`credibilityScore` 72 → 62。
`crossExam.confidenceAdjustment` 为 -10，写入 `finalReport.crossExam`。
`crossExam.ts`：支撑与反证同时非空才升级，最多 2 条。
`compareVerdicts` / `crossExamConfidenceAdjustment`：每次分歧 -10、封顶 -20；第二意见 `unverified` 记 inconclusive，不算硬分歧。
管线在 `finalizeReport` 之后只改分数，不改 `factCheckResult`。
单条复核失败记 inconclusive，不阻断收束。
生产第二模型：`handlers.ts` 的 `pickCrossExamModel`，候选 step-3.7-flash → MiniMax-M3 → mimo-v2.5-pro，先挑与主判不同源。
