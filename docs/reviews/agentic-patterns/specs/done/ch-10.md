## mcpHttpHandler 是否读 Authorization
不读。
`mvp/server/src/lib/mixerMcp.ts` 全文无 `Authorization`、`req.headers`、`auth`。
`mcpHttpHandler` 只读 `req.method` 与 `req.body`。
回环 `runLocalOrchestrate` 只带 `Content-Type`，不转发身份。
`mvp/server/src/index.ts` 的 `app.all("/mcp", …)` 无鉴权中间件。

## runCasePipeline 是否引用 MCP
不引用。
`mvp/server/src/lib/casePipeline/` 无 `mcp` / `MCP` / `mixerMcp`。
`runCasePipeline.ts` 不 import `mixerMcp`。
MCP 只停在 `index.ts` 的 `/mcp` → `mcpHttpHandler` → 本机 `POST /api/agent/orchestrate`。
`handlers.ts` 的 `orchestrateHandler` / `orchestrateStreamHandler` 才 `await runCasePipeline`。
