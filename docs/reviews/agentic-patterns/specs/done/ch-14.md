## 残余风险
`assembleFinalReport` 只有在带上 `atomSearchBundle.byAtomKey` 时才走 bind。
没带 bundle 时，无 URL 的 true/false 仍会进结果页。
整句 `deriveOverallVerdict` / `reportReviewer` 守门留给第 18 章。
用户会看见：单条已是还查不清，整句仍可能写成能信或不能信。
