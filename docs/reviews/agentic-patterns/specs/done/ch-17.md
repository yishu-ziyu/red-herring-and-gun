## ResultView 是否含 ThinkingReasoning
无。
`mvp/src/components/v3/phases/ResultView.tsx` 不 import `ThinkingReasoning`，全文无 `agent_thought`、无「思考中」、无「思考已完成」。
`ThinkingReasoning` 只出现在 `MissionProcessShell.tsx` 与 `MissionThoughtFold.tsx`。
那是核查进行中的过程折页，查完自动折上，不是结果第一眼。
用例：空句且不在思考中 → 组件不渲染；有句才回看。
第一眼仍是 `ResultView` 的能信 / 不能信 / 还查不清。

## agent_thought 是否进对用户说的话
不进。
用例：`agent_thought sentences live on the instrument, not the speech line`。
`flattenRowToBlocks` 的 `speech.text` 是步骤标题，思考句只挂在 `hostsReasoning` 的仪器卡。
`handlers.ts` 的 `onThought` 只发 `type: "agent_thought"` 的 SSE，前端不编句。
没有思考文本就不发。

## 立场条是否「立场型 / 不适用真/假判断」
报告层是。
`ReportModal.tsx` 对 `kind === "stance"` 写徽章「立场型」，说明写「不适用真/假判断」。
用例：`nonVerifiableAtoms` 原位标「立场型」，不订真/假。
用例：整句 `stanceClaimType.verifiable=false` 时顶部横幅也是「立场型」。
管线用例：`顺序：rumor → self-proof 过滤 → 只搜可核查 → assemble 排除立场`。
`searchOne` 只收到「事实A」。
「价值B」进 `nonVerifiableAtoms`，不进 `subclaimVerdicts`。
