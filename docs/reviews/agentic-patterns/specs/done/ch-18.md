## Goal
merge 之后无 http(s) 的 true/false 必须 unverified。
derive 不得把无据之真收成 true，不得让无据之假单独返回 false。
reviewer 整句 true/false 且没有非 related-only 绑定 URL 时收成 unverified。
短谣 boundTiny 例外保留。

`mvp/server/src/lib/reportAssembly/assembleFinalReport.ts`：只改 `deriveOverallVerdict`。有据只认非 related-only 的 http(s)。无据之假不撑整句 false。无据之真不升整句 true。
`mvp/server/src/lib/reportReviewer.ts`：`reviewAndRepairReport` 对整句 true/false 查非 related-only 绑定 URL；没有则降 unverified。false 且 `boundTinyRumorVerdict` 为 false 时留下。
