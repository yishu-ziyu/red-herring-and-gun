左栏「活动过程」改版原型

对照你截图里的问题：假双卡、供应商墙、claim 复读、裁切「立」、过程区抢主舞台。

准备改什么（仅提案，等你拍板）

  1. 左栏默认不是工程师事件瀑布：只保留「现在在干什么」+ 最多 4～6 条人话步骤；完整 12 条日志收进「技术过程」。
  2. 同角色只一张卡：禁止两个「协作核查 / 立案分诊员」并排；状态点覆盖（完成/进行中）。
  3. 标题人话化：返回 | Memory Search → 查过往类似案件；搜索 | 360 / AnySearch / … → 检索公开材料（引擎名只在展开里）。
  4. 禁止全文复读 claim：query 一行截断或写「同正在核查原句」。
  5. 修布局裁切：去掉孤儿「立」字一类坏排版。
  6. 主舞台给结果/线索：等待时右侧是「已出现的线索 + 等什么」；完成后右侧是判决书（判定 / 一句话 / 转发建议 / ≤3 来源）。左栏永远是副栏。
保护：真实事件流、编排、导出机制不删，只改默认暴露层级与文案。首页与结果面板若你满意可不动。
