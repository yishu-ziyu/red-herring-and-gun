## FOLD 1 · HOME

### 1. Persona monologue（口语）

> 群里视频还在弹，我搜了下这个「红鲱鱼」名字挺怪的……打开一看，大标题「当任何人都能生成信息，我们需要重新设计验证信息的方法」——这是作文比赛吗？  
> 下面又来一段「基于多 Agent 协作的事实核查系统」「拆解观点、寻找证据」……我又不是来写论文的。  
> 输入框倒是在，灰色「开始调查」——我还没打字所以灰的？行吧。  
> 再往下：「它如何工作」01 Claim Decomposer、02 Evidence Hunter、03 Source Assessor……英文工种名一排。  
> 什么叫 Decomposer？我要的是：百色这视频假不假，转不转。  
> 底下还有「隔夜菜会致癌」「未来三年营收增长十倍」演示卡——和我现在要查的事没关系。  
> 最底下塞一堆 360 / AnySearch / Metaso / Tavily / Exa · MiniMax / StepFun / DeepSeek……这是在报供应商名吗？  
> 5 秒到了。我还不知道点下去要等多久、会不会给我一个「真/假/不确定」。先关，群里继续吵。

### 2. Analyst · LIFT

| 维度 | 分（1–5） | 观察 |
|------|-----------|------|
| **Value** | 2 | 价值被长文 pitch 盖住。用户要的是「帮我判这条谣言」，首页卖的是「多 Agent 流水线哲学」。 |
| **Relevance** | 2 | 演示卡是隔夜菜 / 营收 / 政策，不是当前洪水视频。Hero 不接「微信群要不要转」场景。 |
| **Clarity** | 1 | 中英夹杂（Claim Decomposer 等）、段落堆叠、供应商名 footer。首屏没有「真/假/未知」预告。 |
| **Anxiety** | 4（高焦虑） | 不知要等多久、不知输出长什么样、不知会不会收费或要 API Key（底部有 API Key 设置入口，徒增「这玩意要配环境？」疑虑）。 |
| **Distraction** | 5 | 五步流水线、现场拆解示例、三张 demo、静态卷宗预览、provider 名 dump、悬浮 FAB。噪音远超任务。 |

### 3. Trust delta

**−2（进门就减）**

- 不像「帮普通人判谣言的工具」，像「创业项目介绍页 + 工程演示」。
- 静态示例报告写「部分成立 / 42/100」——格式对，但首页用错位：用户还没投入，先被体系吓退。
- 信任：产品能跑复杂流程；不信任：产品懂我 30 秒要什么。

### 4. Abandon risk

**High**

5 秒规则直接触发：术语 + 长文 + 无即时价值句。  
很大比例用户根本不会点「开始调查」。

### 2. Analyst · LIFT

| 维度 | 分（1–5） | 观察 |
|------|-----------|------|
| **Value** | 1 | 2 分钟内零「真/假/未知」、零可点来源、零可行动结论。对「要不要转」价值 ≈ 0。 |
| **Relevance** | 2 | 查询文本本身相关，但 UI 全部是 Agent/工具/链路元数据，不是命题对用户的含义。 |
| **Clarity** | 1 | 双「立案分诊员」、标题重复、中英标签墙、事件流数字（4 完成 · 6 运行 · 11 条）无用户语义。状态词（多引擎搜索中 → 证据交叉验证）不解释「离结论还差几步」。 |
| **Anxiety** | 5 | 黄条同时说「没卡死」和「超过 90 秒可重开」——等于承认超时常态。无 ETA、无进度百分比、无中间可读发现。恐惧「被骗浪费时间」被坐实。 |
| **Distraction** | 5 | 左轨近重复工具调用列表 + Agent Team 卡片 + 右轨 Thinking/Search/Sources 工程师面板。主任务（判真假）完全被运维视图淹没。 |

### 3. Trust delta

**−3（调查中继续崩）**

- Early：还能靠「好像在搜」撑一点耐心。
- Mid（~2min）：黄条 + 仍无材料 + 重复 agent 名 → 判定「这是半成品调试台，不是给我用的」。
- 工程师信任可能上升（能看见工具调用）；普通人信任暴跌。
- 产品承诺「事实核查」与交付「等模型返回」的落差是主因。

### 4. Abandon risk

**High（峰值）**

- 目标 30 秒 vs 实测 ~2 分钟仍无结论 → 时间预算击穿。
- 「取消核查」是最显眼的完成感按钮；关窗成本低于继续等。
- 即使用户忍到报告，心理账户已记：「这破东西太慢」。

| 维度 | 分 | 观察 |
|------|----|------|
| **Value** | 0（当前路径） | 未交付报告 = 价值未发生。等待失败即产品失败。 |

**−4 累计（相对进门）**

### 4. Abandon risk

**High（路径级）**

REPORT unobserved 本身就是 abandon 的证据，不是缺口备注。

## 什么会让小陈留下

1. **首屏一句人话**：「粘贴群里的说法，大约半分钟给你：能不能信、能不能转、凭哪几条。」不要哲学开场。
2. **调查中永远有「当前可读结论草案」**：哪怕是「暂判：不确定 · 已找到 0 条权威信源 · 还在搜」——进度是人话，不是 4完成6运行。
3. **30–60 秒内必须出现可扫的证据片**：一条链接标题 + 一句话摘录 + 支持/反驳标签。空 Sources 不可超过用户耐心窗。
4. **报告首屏三行硬信息**：判定（真/假/未知/部分）· 转不转建议 · 最强一条凭据。链路/Agent 名折叠到底。
5. **超时策略反过来**：90 秒应自动给「目前已知」半成品报告，而不是黄条劝重开。

## 什么会让小陈直接关

1. 首页 5 秒仍是 Agent 流水线说明书。  
2. 调查 30 秒后仍是工具调用瀑布 + 英文标签。  
3. 超过约 1 分钟仍无任何「真假倾向 / 来源 / 建议」。  
4. 黄条承认超时并推销「再开一次」。  
5. 永远到不了报告，或报告又是工程师卷宗。

---

## 一句话结论

小陈要的是 **30 秒判谣条**；当前产品给的是 **2 分钟 Agent 工作台 + 无报告**。  
HOME 吓退一半，INVESTIGATING 磨死剩下一半，REPORT 在证据里不存在——放弃风险全程 High，信任单调下降。

**唯一该优化的用户可感知结果：**  
粘贴 → 很快看到「倾向 + 凭什么」→ 决定转不转。其余工程可见性默认折叠。
